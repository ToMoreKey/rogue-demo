# 仕様: 鐘のしずく・ガチャ・ログインボーナス・デイリーダンジョン（2026-11-28 決定）

## 方針（ユーザー決定）
- ガチャの景品は **ゲーム性に影響しない見た目要素のみ**：称号／図鑑の飾り／キャラのおまけ装備（既存の武器防具とは別枠、見た目だけ）を**闇鍋**（同じ抽選に混ぜる）。
- ガチャ用アイテムは **「鐘のしずく」**（ゲーム内入手のみ・課金なし）。入手元＝ログインボーナス／実績の初達成／デイリーダンジョン報酬／初踏破・目標達成。
- 回数制限ダンジョン（1日3回）は **曜日で変わる試練**。初回から遊べるよう、敵の強さはプレイヤーLvに合わせて自動調整。

## ガチャ「福音のくじ」
- 1回 3しずく／10連 30しずく（10連は最後の1枠がSR以上確定）。**天井**: SSRが50回出ないと次はSSR確定。
- 提供割合（画面に常時リンク表示。ストア審査対応）: N 60% / R 28% / SR 10% / SSR 2%。
- ダブり: しずくに還元（N1/R1/SR2/SSR3）。
- 景品 37種: おまけ装備（染め・背中・足元・オーラの4スロット）、ガチャ称号、図鑑の飾り枠。
- おまけ装備は4スロットに1つずつ装備可。戦闘中・ステータス・街のくじ画面で反映。
- 称号は既存の称号一覧に合流（装備もそこ）。図鑑の飾りは図鑑・実績画面の枠に反映。

## しずくの入手
- ログインボーナス: 7日周期 [2,2,3,2,3,3,8]（1日休んでも周期は進むだけ・ペナルティなし）。
- 実績の初達成: max(2, round(回廊コイン/3))。
- ダンジョンの初踏破: 初級1／中級2／上級3（各ダンジョン初回のみ）。
- はじめの目標の達成: 各2。
- デイリーダンジョン: クリア1回につき1＋曜日ボーナス。
- 目安: 毎日遊ぶと1日あたり約1〜2回ぶん。

## デイリーダンジョン「鐘の試練」
- 1日3回（端末の日付が変わると回復）。曜日ごとに報酬の傾向が変わる固定ダンジョン。
- 敵の強さはプレイヤーLvに自動追従。Lv1から参加可能。
