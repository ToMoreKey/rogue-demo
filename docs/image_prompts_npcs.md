# NPC立ち絵プロンプト（ルル＋施設NPC 4人、5キャラ×表情3種）

Gemini（画像生成）に渡す。**参照画像として `char_style_ref.png`（プレイキャラ4人の立ち絵）を必ず添付**してから、各プロンプトを貼る。
出来上がったシートは、私（Claude）が背景を抜いて1枚ずつ切り出し、192×192 に整えて `src/assets/` に埋め込み、NPCの表示（通常／喜び／驚き）に差し替える。

| キャラ | 役割 | 表情の使い分け |
|---|---|---|
| ルル | 広場の案内人（新規） | 通常＝案内 / 喜び＝目標達成・踏破 / 驚き＝ボス撃破・レア入手 |
| ミレイ | 宿屋「満月亭」の女将 | 通常＝入店 / 喜び＝宿泊後 / 驚き＝大ケガ・夜更かし |
| トト | 売却ショップの商人 | 通常＝入店 / 喜び＝売却・購入後（高額売却） / 驚き＝レア装備を売る |
| ガンド | 鍛冶屋の親方 | 通常＝入店 / 喜び＝強化成功 / 驚き＝★高の強化・★9 |
| ノア | 福音銀行の行員 | 通常＝入店 / 喜び＝高額預入 / 驚き＝巨額の預入 |

## 共通ルール（各プロンプトに含めてある）
- **参照画像のプレイキャラと同じ画風**：ドット絵（ピクセルアート）、約2〜2.5頭身のちびキャラ、頭が大きく目が大きい、黒に近い紺の太めの輪郭、やわらかい陰影、アンチエイリアスなし。滑らかなイラスト・ベクター・3D風は不可。
- 3列×1行のシート（同じ大きさのセル3つ）。左から **①通常 ②喜び ③驚き**。**同じ服・髪・ポーズ・位置・大きさ**で、**顔の表情だけ**を変える（体や服は3枚で完全に同じ）。
- 1セルに1人、全身、正面向き、足を揃えて立つ。セルの中央に、セルの高さの約85%で収める。
- 背景は単色のマゼンタ（#FF00FF）。体・服・髪・小物にマゼンタ系（ピンク〜赤紫）を使わない（頬は淡いオレンジ寄りの肌色の赤み）。影・床・文字・枠線・吹き出し・エフェクト（キラキラ等）は入れない。
- 表情の定義：①通常＝口角を少し上げた穏やかな表情 ②喜び＝目を閉じて笑う（弧の形）、口を開けた笑顔 ③驚き＝目を丸く見開き、口は小さな「o」。

## 出来上がったあとの流れ
1. 5枚のシート（PNG）をこちらに渡す。
2. 背景（マゼンタ）を抜き、3表情を切り出して 192×192 に整える（輪郭の縁はプレイキャラに揃える）。
3. NPC の立ち絵を、通常／喜び／驚きで差し替え（喜び＝強化成功・高額売却・高額預入など、驚き＝レア入手・★9など）。
4. 画面で確認 → 直し → dev で確認 → 公開。
