### 0. 前提（これまでと同じ）
- `src/` を編集し、`python3 tools/build.py` で `index.html` を生成する。`index.html` は直接編集しない。`sw.js` の `CACHE` を上げる。`src/assets/` は触らない（画像を新規に作らない。既存の `ENEMY_IMG`・装備アイコン・CSS・文字・絵文字で作る）。
- `window.__rogue` と `window.G` を残す。外部ライブラリを追加しない。
- 作業は `dev` ブランチ。`main` には push しない。push はこれまでと同じ方法（トークンは設定ファイルから読み、その場の変数で使い、画面・ログ・報告・ファイルに出さない。使用後に変数を破棄）。
- **本編・回廊・深淵のバランスとBOT結果を変えない**（本編周回: ラン数490〜493、`model_hours` 20.85〜20.94、1階あたりティック4.06〜4.13、Lv124。回廊: 最適59/64/69、ランダム51/53/59。深淵BOTも変えない）。報酬は**回廊コインと称号だけ**にして、本編のゴールド・SP・EXP・ドロップには影響させない。
- セーブは追加のみ。既存セーブ（v1〜最新）が壊れないこと。形式を変える場合は `migrations` に追加し、`tools/test_save_migration.py` を更新する。
- 420px幅で画面が崩れないこと（横スクロールが出ない）を、スクリーンショットで確認する。

### 1. ゴール
敵図鑑と装備図鑑を追加し、「見た・倒した・入手した」を記録して一覧できるようにする。未発見はシルエットで見せ、集める動機にする。

### 2. やること

#### 2-1. データと記録
- セーブに `p.dex = { enemies: { [敵ID]: { seen: true, kills: 数 } }, items: { [キー]: true } }` を追加する（キーの形式は `weapon_5` `armor_8` `weapon_m8` `armor_m9` など。神話は別キー）。
- **敵の記録**: 敵が出現したとき `seen = true`、撃破したとき `kills++`。対象は全ダンジョンの通常敵・ボス、`o_boss_rage`（怒り形態に切り替わったとき）、深淵の主3体（`abyss_gula` `abyss_mirror` `abyss_deep`）。回廊・深淵で出る既存敵も同じIDで記録する。強敵・上位種は元の敵IDで記録してよい。
- **装備の記録**: 武器・防具を入手（ドロップ・購入・交換・鍛冶で作成）したとき、`slot_★` を記録する。神話レアは `slot_m★`（交換品の★8、ドロップの★9）。
- 既存セーブへの引き継ぎ（移行）: すでにクリア済みのダンジョン（`p.cleared`）の敵は `seen` に、現在の装備・所持品と、それらの★に応じた装備は `items` に反映する。撃破数は不明なので0でよい（`seen` だけ）。バージョンを上げて `migrations` に追加する。

#### 2-2. 画面
- 入口: ステータス画面に「図鑑」ボタンを置く（またはステータスのタブ）。モーダルで開き、「敵」「装備」の2タブ。
- **敵図鑑**: ダンジョン（A〜O、深淵）ごとにまとめる。1体ずつカード（既存の `ENEMY_IMG` の画像。未登録の敵は既存のドット絵を使用）。見た敵は名前・撃破数・ダンジョン名。**未発見はシルエット**（画像を `filter: brightness(0)` などで黒くし、名前は「？？？」）。ダンジョンごとに「発見 n/6」を表示。上部に全体の発見数（例: 「発見 45 / 94」）。420px幅は3列。
- **装備図鑑**: 武器・防具の2段 × ★1〜9 の格子（既存の装備アイコン）。入手済みは通常表示、未入手はシルエットと、タップで入手条件のヒントを出す。ヒントの例: ★5=Cダンジョン以降のドロップ、★6=上級石で強化、★7=時の欠片（D〜Fのボス）で強化、★8=機神の核（H・Iのボス）で強化、★9=創世の欠片（Oのボス）で強化。神話は別枠で、★8（回廊コイン交換）と★9（深淵の主の低確率ドロップ）の2種を、武器・防具それぞれ表示する。上部に「入手 n/22」。
- ネタバレ配慮: 未発見の敵の名前は表示しない。装備のヒントは、入手条件のみ（ドロップ率の数値は出さない）。

#### 2-3. 図鑑の報酬（回廊コインと称号のみ）
- ダンジョンの敵をコンプリート（そのダンジョンの通常敵5＋ボス1）で、回廊コイン 5枚（1回だけ。深淵の主3体の図鑑は計15枚）。
- 敵図鑑を全コンプリートで、回廊コイン 100枚と称号「図鑑博士」。装備図鑑を全コンプリートで、回廊コイン 100枚と称号「蒐集家」。
- 報酬は、画面の「受け取る」ボタン（または自動付与＋トースト）で受け取る。二重に受け取れない。称号は既存の称号の仕組み（`p.tower.titles`、`TOWER_TITLES`）に追加する（既存のデータ表を拡張）。
- 本編クリア前でも図鑑は記録・閲覧できるが、**回廊コインは本編クリア後に受け取れる**（`p.ending` 前は「🔒 本編クリアで受け取り可能」）。コインは本編のバランスに影響しない。

#### 2-4. BOT・テスト
- `tools/test_p6a.py` を追加し、`README.md` に実行方法を書く。内容: 敵の出現・撃破で記録される、装備の入手で記録される（神話は別キー）、移行（既存のクリア済みセーブ）、図鑑の画面（未発見はシルエットと「？？？」、発見数の表示）、ダンジョンのコンプリート報酬が1回だけ、本編クリア前は受け取れない、420pxで横スクロールなし。
- 既存テスト（`test_p1` 〜 `test_p5b2`、`test_save_migration`）がすべて通る。本編周回・回廊・深淵のBOT結果が変わらない。ビルドが再現できる。
