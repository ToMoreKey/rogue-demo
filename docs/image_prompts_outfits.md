# 衣装画像 Gemini プロンプト（各キャラ × 5種）

## 共通ルール
- 添付画像: そのキャラの通常スプライト（`src/assets` の idle 画像）を参照として必ず添付し、「同じキャラクター・同じ画風・同じドット絵の粗さ・同じ向き・同じ体型比率」で衣装だけ変えるよう指示する。
- 仕様: 192×192 px 相当 / 背景は完全な透明（PNG）/ 影・床・文字・枠なし / 髪色・顔・体型は元のまま。
- 水着・バスタオルは健全な表現にする（スポーティな水着＋パーカー、バスローブ風の「湯上がり」）。肌の露出を強調しない。
- 攻撃ポーズ（任意）: `<key>_<skin>_atk.png`。無ければ攻撃時の差し替えは行われない。

## 命名（tools/make_outfit_assets.py 用）
`<key>_<skin>.png` / `<key>_<skin>_atk.png`
key: sailor（セーラー服, SR）/ blazer（ブレザー, SR）/ nurse（ナース, SR）/ swim（水着, SSR）/ towel（湯上がり, SSR）
skin: ruby / stella / silia / chloe

## プロンプト雛形（{CHAR} と {OUTFIT} を差し替え）
添付のドット絵キャラクター（{CHAR}）と同一人物のまま、衣装だけを {OUTFIT} に変更した新しいドット絵を作成してください。
- 画風・ドットの粗さ・色数・輪郭線・向き・頭身は添付画像と完全に一致させる
- 髪型・髪色・顔・持ち物以外のシルエットは変えない
- 192×192、背景は完全に透明、影や地面は描かない
- 元スプライトに武器がある場合は衣装に合う小物に置き換えてよい
- 攻撃ポーズ版は、元の攻撃スプライトと同じポーズで同じ衣装にする

## {OUTFIT} の指定文
- sailor: 白と紺のセーラー服（赤いスカーフ、プリーツスカート、紺のハイソックス）
- blazer: 紺のブレザー制服（チェックのプリーツスカート、リボンタイ、ローファー）
- nurse: 白いナース服（ナースキャップ、淡いピンクのアクセント、白い靴）
- swim: スポーティな水着に薄手のパーカーを羽織った姿（露出控えめ、浮き輪やビーチサンダルなどの小物可）
- towel: 湯上がりの姿（ふわふわのバスローブ、頭にタオル、ほんのり頬が赤い）

## キャラ一覧
- ruby / stella / silia / chloe（{CHAR} には各キャラ名と特徴を入れる。特徴は docs/world_setting.md 参照）

## 取り込み手順
1. 画像を1フォルダに置く 2. 「このフォルダで取り込んで」と伝える（`python3 tools/make_outfit_assets.py <フォルダ>`）3. 取り込んだ衣装のみガチャ景品に追加される
