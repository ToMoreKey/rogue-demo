> **注意（2026-11-28）**: 広告・課金を入れる方針になったため、アプリ化は TWA ではなく Capacitor 方式に変更。手順は `docs/native_release_guide.md` を見る。このファイルの §0（用意済みのもの）・§4（申告）・§5（ストア文面）は引き続き有効（申告は広告あり・課金ありに読み替え）。

目的: 公開中のPWA（https://tomorekey.github.io/rogue-demo/）を、Android アプリ（AAB）として Google Play に出す。
役割: 資料・画像・文面は Claude が用意済み。**アカウント登録・署名キー・申請ボタンは運営者の操作**。

## 1. 事前に決めること
- **パッケージ名**（後から変更不可）: 例 `io.github.tomorekey.kanenari`
- **連絡先メール**: ポリシー・ストア掲載に載る（公開される）。専用アドレス推奨。
- **デベロッパーアカウント**: 個人は登録料 $25（1回）。個人アカウントは、**製品版公開の前に「クローズドテストで一定人数が一定期間テスト」する要件**が課されることがある（人数・日数は Play Console 上の最新の表示に従う）。知人のテスター集めを今から。

## 2. 最大の注意: ドメイン検証（assetlinks.json）
TWA でアドレスバーを消すには、ドメインの**ルート**に `/.well-known/assetlinks.json` が必要。
- このゲームのURLは `tomorekey.github.io/rogue-demo/`（サブパス）。`tomorekey.github.io/.well-known/` は**このリポジトリでは配信できない**。
- 対処（どれか1つ）:
  1. **ユーザーサイト用リポジトリ `ToMoreKey/ToMoreKey.github.io` を作り**、そこに `.well-known/assetlinks.json` を置く（`.nojekyll` も）。ゲームのURLはそのまま。**推奨**。
  2. 独自ドメインを取得して Pages に割り当てる。
  3 検証なしで出す（アドレスバー付きの表示になる。見た目が劣るため非推奨）。
- `assetlinks.json` の中身（SHA-256 は §3 の手順で入手）:
```json
[{"relation":["delegate_permission/common.handle_all_urls"],
  "target":{"namespace":"android_app","package_name":"<パッケージ名>",
  "sha256_cert_fingerprints":["<Play Console の アプリ署名 SHA-256>"]}}]
```

## 3. アプリ化の手順（PWABuilder・インストール不要）
1. https://www.pwabuilder.com/ に本番URLを入力 → 診断（manifest・Service Worker は済み）。
2. 「Package for stores」→ Android → パッケージ名・アプリ名「鐘鳴りのダンジョン」・バージョン 1 を入力。
3. 署名は「新しい署名キーを作る」を選び、**ダウンロードした `signing.keystore` とパスワードを安全な場所に保管**（紛失するとアップデート不可。Play App Signing を使うなら、アップロード鍵として扱う）。
4. 生成された `.aab` を保管。
5. Play Console → アプリを作成 → 製品版/テストに `.aab` をアップロード。**アプリの署名 SHA-256**（アプリの完全性 → アプリ署名）を `assetlinks.json` に入れて §2 の場所へ公開。
6. 実機（Android）にインストールし、アドレスバーが出ないこと・起動・戦闘・セーブを確認。

## 4. Play Console の申告（回答案）
### データセーフティ
- 収集するデータ: **アプリのアクティビティ／診断（任意・匿名）**、**その他のユーザー生成コンテンツ（ニックネーム＝ランキング。任意・同意制）**。個人を特定する情報・位置情報・連絡先・金融情報は**収集しない**。
- 第三者共有: Googleフォームへ送信（サービス提供のための処理者として）。販売はしない。
- 暗号化: 通信は HTTPS。 / 削除リクエスト: ポリシーの連絡先経由（ランキングのニックネーム）。
- 匿名送信はアプリ内（ステータス＞データ）でオフにできる。
### コンテンツレーティング（IARC）
- 暴力: ファンタジー系の戦闘（血の表現なし）／ 性的内容: なし（衣装は健全な範囲）／ 賭博: なし ／ 課金: なし ／ ユーザー間交流: なし（ランキング表示のみ）。
- ターゲット年齢: 全年齢（13歳未満を含めると「ファミリー」ポリシーの対象になりうるため、**ターゲットは13歳以上**にするか、含める場合はポリシー確認が必要。要判断）。
### 広告・課金
- 広告: なし／アプリ内課金: なし（鐘のしずくはゲーム内入手のみ・現金購入不可）。ガチャの提供割合は画面に表示済み。
### AI生成コンテンツ
- キャラクター・敵・衣装などの画像は AI（画像生成）で作成。Play の「AI生成コンテンツ」関連の申告欄・審査での説明が求められる場合は、「画像素材に生成AIを使用。不適切な出力が出ないよう制作者が確認・選別」と回答。
- ストア掲載画像（スクリーンショット等）は実際のゲーム画面。

## 5. ストア掲載文（案）
**アプリ名**（30字以内）: 鐘鳴りのダンジョン
**短い説明**（80字以内）: 鐘の音を取り戻せ。4人の勇者とルート式スキルで育てる、自動戦闘のローグライクRPG。
**詳しい説明**:
```
鐘の音が弱まった「福音の里」。あふれ出す魔物を倒し、鐘の音を取り戻す冒険に出かけましょう。

■ 自動戦闘でサクサク
ダンジョンに潜ると戦闘は自動で進みます。装備とスキルを整え、危なくなったら撤退。何度でも挑戦できます。

■ 4人の勇者と、ルート式スキルツリー
剣士・魔法使い・聖職者・盗賊。キャラごとに「2つのルート」から1つを選んで育成。選ぶルートで戦い方が変わります。ビルドは最大3つまで保存できます。

■ やり込み要素がたっぷり
・全15のダンジョン（5段階の難易度）
・毎日挑戦できる限定ダンジョン「鐘の試練」
・無限回廊「天蓋の塔」とランキング
・全50階の「深淵」
・装備の強化・神話装備・図鑑・実績

■ 福音のくじで着せ替え
ゲームで貯めた「鐘のしずく」でくじを引いて、衣装や髪染めを集めよう。景品は見た目だけ。現金での購入はありません。

■ 安心の仕様
・広告なし／アプリ内課金なし
・ゲームの進行データは端末内に保存
```
