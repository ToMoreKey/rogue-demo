# 実装メモ: R1c（4キャラのバランス調整）

実装: Claude。BOTは `tools/bot.py --seeds N`（既定3）で8シード×4キャラが約1分で回る。`defeatList`（敗北が起きたダンジョン×Lv）も出力。

## 調整前（8シード平均）
| キャラ | 周回 | 敗北 | model_hours |
|---|---|---|---|
| ステラ | 499.2 | 15.6 | 21.01 |
| ルビィ | 510.6 | **38.5（最大66）** | 21.19 |
| シリア | 500.6 | 17.0 | 21.04 |
| クロエ | 507.4 | 27.0 | 21.20 |

ルビィの敗北はLv8〜11（Cnovice）・Lv18〜27に集中（成長途中）。

## 原因と調整（ルビィ）
1. **マジックシールドが未実装**（効果なし・ターンで切れずオーラが出っぱなし）→ 説明どおり実装：5ターン、防御力1.5倍（敵の攻撃ごとに1減る）。説明文の「魔法防御力」→「防御力」。
2. **ファイアボールが強撃の下位互換**（MP12/CT3/1.8倍 vs 強撃 MP6/CT2/2.0倍）→ MP8/CT2/2.0倍に。
3. **サンダー** MP18→14（連続斬りと同水準）。
4. **魔術師枠パッシブ（mage10）**: 「MP消費-20%」に**攻撃力+15%**を追加（ルビィは攻撃・HPのパッシブを持たず他キャラより脆かったため）。名称「MP消費-20%・攻撃+15%」。
   - 経緯: 効果は周回数のみに出て敗北数は不変＝序盤の問題と判明し、2・3で改善。
