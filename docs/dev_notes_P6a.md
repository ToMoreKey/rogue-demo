# P6a 開発メモ（敵図鑑・装備図鑑）

## 1. 記録対象とセーブ（v6）

- **セーブ形式 (`SAVE_VERSION = 6`)**: `p.dex = { enemies: { [敵ID]: { seen: true, kills: 数 } }, items: { [キー]: true }, rewards: { [報酬キー]: true } }` を追加。
- **移行 (`migrations[5]`, v5 → v6)**:
  - `p.cleared` でクリア済みのダンジョンの通常敵5体＋ボス1体（O極級クリア済みなら `o_boss_rage` も）、`p.abyss.cleared` に応じた深淵の主を `seen: true, kills: 0` として引き継ぎ。
  - 現在の `weapon` / `armor` / `bag` の装備を `items` に引き継ぎ（初期装備の `weapon_1` / `armor_1` も登録）。
- **敵図鑑（計94種）**:
  - 本編ダンジョン A〜O（各 通常敵5＋ボス1 = 90種）＋ `o_boss_rage`（終焉神ニヒル・真、1種）＋ 深淵の主3種（`abyss_gula`, `abyss_mirror`, `abyss_deep`）。
  - 出現時に `seen = true`、撃破時に `kills++`。回廊・深淵で出現する既存敵は元の敵IDで記録。
- **装備図鑑（計22種）**:
  - 通常（`weapon_1..9`, `armor_1..9` = 18種）＋ 神話レア（`weapon_m8`, `weapon_m9`, `armor_m8`, `armor_m9` = 4種）。
  - 入手（ドロップ・交換・鍛冶強化）時に記録。

## 2. 画面仕様

- ステータス画面に「📖 図鑑」ボタンを配置し、モーダルで「敵図鑑」「装備図鑑」の2タブを表示（420px幅で3列グリッド・横スクロールなし）。
- 未発見の敵はシルエット（`filter: brightness(0)`）＋名前「？？？」でネタバレ防止。
- 未入手の装備はシルエット＋タップで入手条件ヒントを表示（ドロップ率数値は非表示）。

## 3. コンプリート報酬（回廊コインと称号のみ）

- **ダンジョン単位**: A〜O 各コンプリート（通常敵5＋ボス1）で回廊コイン **5枚**、深淵の主3体コンプリートで **15枚**（各1回のみ）。
- **全コンプリート**:
  - 敵図鑑全94種: 回廊コイン **100枚** ＋ 称号 **「図鑑博士」**（`t_dex_en`）
  - 装備図鑑全22種: 回廊コイン **100枚** ＋ 称号 **「蒐集家」**（`t_dex_it`）
- 本編クリア前（`!p.ending`）は「🔒 本編クリアで受け取り可能」と表示し、受け取り不可（本編バランス非干渉）。
