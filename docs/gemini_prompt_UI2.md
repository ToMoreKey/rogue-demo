# Gemini 向け指示書: UI-2（ヘルプ画面の項目分け）

## 【プロンプト本文（ここから貼り付け）】

あなたは、ブラウザで動くローグライクRPG「rogue-demo」の開発担当エンジニアです。リポジトリ `ToMoreKey/rogue-demo` の `dev` ブランチ（最新を取得してから）で作業します。今回は UI-2「ヘルプ画面の項目分け」です。仕様と合格基準は `docs/change_UI2_help.md`、実装の手本は完了済みの UI-1（`docs/change_UI1_status.md`、`docs/dev_notes_UI1.md`、`renderStatus` のタブ実装）です。

### 0. 前提（UI-1と同じ）
- `src/` を編集し `python3 tools/build.py` で `index.html` を生成。`index.html` は直接編集しない。`sw.js` の `CACHE` を上げる（CRLFの改行を保つ）。`src/assets/` は触らない。
- `window.__rogue` と `window.G` を残す。外部ライブラリは追加しない。
- 作業は `dev`。`main` には push しない。push は従来どおり（トークンは設定ファイルから読み、その場の変数で使い、画面・ログ・ファイル・コミット・報告に出さず、使い終わったら破棄）。既存コミットの書き換え・force push はしない。
- `#app` のスクロール・下部ナビ固定・モーダルのsticky下端ボタンを壊さない。

### 1. やること
`docs/change_UI2_help.md` の3〜4章を実装する。
1. ヘルプ画面（`renderHelp`）に5つのサブタブ（はじめに／街・迷宮／スキル／ステータス／後編）を置く。UI-1のタブバー実装・CSSを共通化して再利用する（重複定義しない）。
2. 既存の7パネルを、ちょうど1タブに割り当てる（中身は変えない）。ただし「ステータスタブでできること」は、UI-1後の5タブ構成に合わせて文言を書き直す。
3. 選択状態は `G.helpTab`（メモリのみ・初期は「はじめに」）。切替でスクロールを上に戻す。再描画で戻らない。
4. チュートリアル（step 6 ほか）、`#help-endgame` への誘導、他画面のヘルプ案内文の連動を確認し、必要なら直す。

### 2. 守ること（厳守）
- 数値・バランス・BOT結果・セーブ形式(v8)・新しい保存キー禁止・`to_dev` の分離を壊さない。
- 仕様と矛盾する判断は勝手に決めず「要確認」と書く。
- `tools/test_ui2.py`（新規）を追加し、`README.md` に実行方法を書く。合格基準1〜5を360/390/420pxでテストする。
- 全テスト（test_p1〜最新、test_save_migration、test_variants、test_noskip、test_p8、test_p9、test_modal_close、test_layout、test_ui1）が `RESULT: OK`。ビルドが `cmp` で再現できる。本編BOTが変わらない（ラン数490〜510、model_hours 20.8〜21.2、Lv124）。テストを通すために判定を弱めない。
- 実装メモを `docs/dev_notes_UI2.md`（新規）に残す（390×844 で各タブを確認した結果も文章で）。
