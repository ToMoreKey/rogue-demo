## 2. 修正した不具合

1. **ステータス画面の防具防御力表示に「聖域 (`aegis`)」特性が反映されない**
   - **原因**: `src/js/60_render.js` の `renderStatus()` 内で、`playerDef(p)` は `armorDef(p.armor)` を使っているのに、内訳表示の「防具 ○」が `itemPower(p.armor)` を参照していた。
   - **修正**: `armorDef(p.armor)` に統一し、`80_boot.js` に `armorDef` を公開、`sw.js` の `CACHE` を `rogue-v24` に更新、`tools/test_debug1.py` に再発防止テストを追加。

## 3. 要確認（仕様か不具合か判断しない・数値・セーブ形式に関わる項目）

1. **既存パッシブの `atkMult` / `healMult` が戦闘計算で未参照（既知・P5b1修正時から据え置き）**:
   - `passiveBonus(p)`（`src/js/10_art.js`）で計算されている `sword15`/`warrior10`/`hero10` の `atkMult` と `cleric10` の `healMult` は、`playerAtk` や回復計算に掛けられていない（P5b1修正時の取り決めどおり、数値バランス不変のためそのまま維持。P7で要確認）。
2. **ヘルプ画面の初期文言がデモ版（A〜C・最大★5）のまま**:
   - 「街タブでできること（鍛冶屋 最大★5）」「ダンジョンタブでできること（A→B→Cの3種）」は既存ヘルプの文言変更禁止ルールに従い未変更。P7または次期対応で更新するか要確認。
