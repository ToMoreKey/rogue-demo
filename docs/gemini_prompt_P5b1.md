#### 2-0. 前回（P5a）の小修正

#### 2-1. 深淵ダンジョン
- **解放条件**: 本編の全15ダンジョン（A〜O）の**極級をクリア済み**。未解放のときは、ダンジョン一覧に「🔒 深淵（全ダンジョンの極級をクリアで解放）」と、あと何個かを表示する。
- 一覧には「天蓋の塔」と並ぶ別枠のカード（「深淵」）として表示。難度の選択（1〜10）を持ち、難度Nは難度N-1をクリアすると解放（難度1は最初から）。クリア済みの最高難度を記録する。
- **構成**: 1回の挑戦は**50階固定**。敵は本編の全敵（`DUNGEONS` の通常敵）から、階層に応じた帯のものを混ぜて出す（P5aの回廊と同じ考え方でよい。帯の割り当てを `docs/dev_notes_P5b1.md` に表で残す）。10階ごとに節目の強敵（既存の仕組み）。**50階（最終階）に深淵の主**: 難度1〜3は `abyss_gula`（喰らう深淵グラトス）、難度4〜7は `abyss_mirror`（映す深淵ミラージュ）、難度8〜10は `abyss_deep`（沈める深淵アビサル）。画像は `ENEMY_IMG` に既にある。**難度3・6・10は、難度の最終ボスとして、各主の強化版**（名前に「・極」などの接頭辞、HP/ATKを上乗せ）にしてよい。
- **呪い（累積）**: 難度が1上がるごとに呪いが1つ増える。難度Nでは、呪い1〜Nがすべて有効。10種を `src/data/abyss.js`（新規）にデータで持たせる。固定の2つ: 呪い1「回復量-50%（ポーション・回復スキル・泉）」、呪い2「スキルのCT+1」。残り8つは、次のような案から、バランスと面白さを見て決める（重複しないこと）: 敵ATK+15%、敵HP+25%、MP最大値-30%、ポーションの効果-50%（呪い1と別枠）、毎階の小休止回復の廃止、ボスの攻撃が強化される、敵が先制する確率、装備ドロップ率-50%、HPの自然回復が止まる、被ダメージ+20%など。戦闘計算の既存の倍率・加算フックに乗せる。挑戦前に、有効な呪いの一覧を表示する。
- **敵の強さ**: 難度ごとに敵ステータスを段階的に引き上げる。難度1は、標準ビルド（Lv126、★8〜9装備、全スキル習得）で、回廊の40階前後と同程度の手応え。難度5までは標準ビルドで遊べる（初回クリア率 難度1〜3は70%以上、難度4〜5は40〜70%）。難度6〜10は、神話装備・共通パッシブ・進化第3段階まで揃えたビルドが前提（標準ビルドではほぼ勝てなくてよい。難度10は「揃えても厳しい」水準）。
- **報酬**: クリアゴールドとSPは本編より小さめ（深淵は周回用）。回廊コインを、難度に応じて少量（難度1=10枚 〜 難度10=100枚など）。装備ドロップの上限は★8まで。神話装備は主のドロップのみ（2-3参照）。
- 全滅・撤退は通常のダンジョンと同じ扱いでよい。深淵では、回廊の祝福は使わない。
- セーブ: `p.abyss = { best: 0, cleared: {1:true,...} }` のような形を追加する。

#### 2-2. 余りSPの使い道
現状、Lv124で未使用SPが約91残る（Lv140では約107）。次の2つで使い切れるようにする。**消費するSPの総量は、Lv140時点で得られる総SPの約110%**になるように設計する（全部を取りたいやり込み派が足りないと感じる量）。総SP量の計算式と、各項目のコストを `docs/dev_notes_P5b1.md` に表で残す。

**(a) 進化スキルの第3段階（本編クリア後に解放）**
- 進化ツリー（戦士・魔法使い・僧侶・勇者）の最大SPを、P3の20からさらに拡張し、**本編クリア（`p.ending`）後に、第3段階として新スキルを取得できる**ようにする（未クリアでは「🔒 本編クリアで解放」と表示）。
- 新スキル: 戦士・魔法使い・僧侶は各2つ（SP25・SP30到達時）、勇者は3つ（SP22・SP26・SP30）。新スキルは既存のスキルの延長として、数値と演出（文字と簡単なエフェクトでよい。画像は作らない）を決める。威力は、本編終盤の最強スキルの1.3〜1.8倍程度。
- 戦闘中に使えるスキル枠（3枠）は変えない。新スキルを使うかどうかは、枠の選択に委ねる。

**(b) 全キャラ共通のパッシブ（「極意」）**
- **本編クリア（`p.ending`）後にのみ振れる**。最初は「🔒 本編クリアで解放」と表示し、SPを振れない。
- 項目は10〜15種。各項目は最大ランク10で、1ランクごとに小さな効果（例: 攻撃力+1%/ランク、防御力+1%、最大HP+1.5%、最大MP+1.5%、クリティカル率+0.5%、ドロップ率+1%、EXP+1%、ゴールド+1%、スキルCT-1%、回復量+1.5%、被ダメージ-0.5%、探索中の小休止回復+など）。コストはランクごとに増える（例: 1ランク目=2SP、10ランク目=6SP）。
- SPのリセット（有料）の対象に含める（既存のSPリセットの仕様に合わせる）。
- 効果は戦闘計算の既存のパッシブ（`passiveBonus`）に乗せる。**本編（A〜O）のBOTの結果を変えない**: 本編クリア前はSPを振れないので影響はないはず。BOTが本編クリア後にSPを振る場合は、その分でバランスが崩れていないかも確認する（深淵と回廊の難度の目安には、振った状態を使う）。
- UI: ステータス画面に「極意」のタブ（またはスキル画面の一角）を追加する。420px幅で崩れないこと。

#### 2-3. ★9の神話装備（深淵の主の固有ドロップ）
- **入手先は深淵の主のみ**（回廊のドロップ・交換所には出さない）。ドロップ率は**極めて低く**する: 目安として、難度3の主=0.5%、難度6の主=1%、難度10の主=2%（難度10の強化ボスは2%、その他の難度は0.5〜1%）。1回のクリアで、武器または防具のどちらか（ランダム）。装備できるのは、武器「創世の剣」と防具「創世の鎧」の神話レア版（名前の接頭辞は「神話の」）。基礎値は★9の既存値（ATK280、DEF140）×神話倍率6.0。**交換品（★8神話: ATK190、DEF95）より、基礎値で明確に高い**。
- **特性（付与される能力）のランダム要素**: 現状、交換品の神話装備は、武器に特性が0〜1個（`it.prop`、既存の仕組み）、防具には特性がない。**ドロップ品は、特性の数が交換品の最大より最大2つ多くなりうる**ランダムにする:
  - 武器: 特性数は 0〜3個（交換品の最大1個に対して、最大で+2個）。個数の確率は 0個=15%、1個=40%、2個=30%、3個=15% を目安にする。
  - 防具: 防具用の特性を新しく数種類つくる（例: 反撃、HP吸収の防御版、被ダメージ軽減、状態異常の耐性、HP自然回復など。既存の `PROPS` の形式に合わせる）。特性数は 0〜2個（交換品の最大0個に対して、最大で+2個）。確率の目安は 0個=30%、1個=45%、2個=25%。
  - **特性の重複はしない**。既存の「狂気」武器の自動装備の除外ルール（`gearScore`）を壊さない。複数特性のときの `gearScore`・戦力値の評価式を、報告に書く。
  - アイテムのデータ形式を、複数特性に対応できるように拡張する（例: `it.props` の配列。既存のセーブ・既存の装備は `it.prop` のままでも動き、移行で変換される）。再鍛造（特性の振り直し）は、複数特性のときの扱いを決める（神話のドロップ品は、再鍛造すると特性数も振り直しになる、など）。報告に書く。
- ドロップ品を拾った演出: 特別なメッセージ（例: 「深淵の主から神話の創世の剣が落ちた！」）を戦闘ログとモーダルに出す。
