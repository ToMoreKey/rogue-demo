# 変更書: UI-2（ヘルプ画面の項目分け）

## 1. 背景
UI-1（ステータス画面のサブタブ化）が運営者確認済み（2026-11-24）。ヘルプ画面も、初心者ガイド・街・ダンジョン・スキル・ステータス・ヒント・後編が縦に並んでいて探しにくい。同じ方式でサブタブ化する。

## 2. 方針
UI-1と同じ仕組み（サブタブ行、sticky、`G.helpTab` はメモリのみ、切替でスクロールを上に戻す、`role=tablist/tab`、`aria-selected`）。タブバーの見た目・CSSはUI-1のものを共通化して使う（重複定義しない）。

## 3. タブの分け方（5つ。1行に収める）
| タブ | 中身（既存パネルをそのまま移す） |
|---|---|
| はじめに | 初心者ガイド（撤退の説明・4ステップ）、その他のヒント |
| 街・迷宮 | 街タブでできること、ダンジョンタブでできること |
| スキル | スキルシステムガイド（習得できるスキル一覧を含む） |
| ステータス | ステータスタブでできること（UI-1の5タブ構成に合わせて文言を更新する） |
| 後編 | 後編・クリア後の要素ガイド（`#help-endgame`） |

- 既存パネルは、**ちょうど1つのタブに入る**（欠落・重複なし）。中身の文言は、UI-1でタブ化された「ステータス」の説明部分以外は変えない。
- 初期タブは「はじめに」。

## 4. 連動（必ず確認）
- チュートリアル step 6 は「ヘルプタブを開く」。ヘルプ内の特定要素を指す手順があれば、その手順で該当タブに自動切替する。`test_noskip.py` が通ること。
- `#help-endgame` へのリンク・スクロール（他画面から後編ガイドへ誘導している箇所）があれば、「後編」タブに切り替えてから移動する。
- 他画面にある「ヘルプの○○を見てください」という案内文は、タブ名に合わせて直す。
- 「ステータスタブでできること」パネルの説明は、現在の5タブ（勇者／装備／スキル／極意／データ）に合わせて書き直す（事実と食い違う文言を残さない）。

## 5. 守ること
数値・バランス・BOT・セーブ形式(v8)・`to_dev`の分離は変えない。新しい保存キーは作らない。外部ライブラリを追加しない。

## 6. 合格基準
1. 5タブが360/390/420pxで1行、横スクロールなし、高さ40px以上。
2. 全7パネルがちょうど1タブに入る（テストで見出しを集めて確認）。
3. スクロールしてもタブバーが上端に残り、切替でスクロールが上に戻る。
4. 再描画・他画面から戻っても選択タブが保持される。
5. チュートリアルが最後まで進む。
6. 全テストOK、ビルド再現、BOT結果不変。
