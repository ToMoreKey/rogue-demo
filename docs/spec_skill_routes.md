# スキルツリーのルート式化（v125）

## 概要
各キャラの分岐ツリー（剣/戦士 等）を「共通枠 + ルートA + ルートB」に分割。共通枠を `at` SPまで振るとA/Bが解放され、**どちらか一方のみ**取得可。共通+ルート=30SP（従来と同じ）。
ツリー構成（キャラ毎7本）: 共通 / A / B / 第2共通 / 第2A / 第2B / 英雄枠。
- 排他: 片方に1SPでも振ると他方は `unlockWhen` で閉じる。リセットで選び直し可（ゴールド消費）。
- 第2ツリー系は従来の解放条件（エンディング到達）を引き継ぐ。英雄枠は通算ポイントで判定。
- 共通枠をリセットすると依存するルート・後続も戻り、SPは返却。

## 追加スキル（9）
shuraSlash, thunderGod, holyBarrage, heavenLight, smite, assassinate, nightFall, counterBlade, mirageBlade

## 旧セーブ移行
共通枠の超過SP・解放条件を満たさなくなったツリーのSPを返却し、初回のみトースト表示（`p.routeNotice`）。

## 注意点
- ルートBには一部の最高火力スキルが入らない（意図的な取捨選択）。
- ツリーリセットはゴールド消費。
- テスト: `tools/test_q4_routes.py`
