# 変更書: R1b（キャラ専用スキルの新規設計：データ・仕組み）

R1（`change_R1_char_classes.md`）の続き。R1aで仕組みは完成済み。R1bでは、暫定だった各キャラのツリーを本設計に差し替え、新規スキル・新パッシブ・汎用バフの仕組みを入れる。
- **R1b-1（今回）**: スキル/ツリーのデータ、新パッシブ、汎用バフの仕組み、BOTのキャラ別装備、テスト。演出は**仮**（分類ごとの汎用演出にフォールバックでよい）。
- **R1b-2（次）**: 新規スキルの個別エフェクト（Q3方式）。
- **R1c（その後・私が実施）**: 4キャラのBOTでバランス調整。**今回の数値は初期案で、R1cで調整する前提**。
- 本番公開は全部そろってから。

## 1. 方針
- 4キャラとも「主ツリー30SP＋第2ツリー30SP＋奥義ツリー30SP」。ステラのツリーの強さ（倍率・MP・CT）を基準に、同じ位置のスキルは同等の強さにする（下表の「基準」列）。
- 奥義ツリー（英雄枠）の**強化系（英雄の覚醒・勇者の光臨・全能力+25%）は全キャラ共通**（既存ID `heroAwaken`/`heroAdvent`/`hero10` をそのまま使う）。**攻撃系はキャラ専用**。
- 習得・装備はキャラごと（R1aの仕組み）。同じIDを複数キャラが持ってよい。
- 非ヒーラーの自己回復は、`firstAid`（応急手当、回復20%）のみ（R1a済み）。強い回復はシリアだけ。

## 2. 新しい仕組み
1. **新パッシブ2つ**（`passiveBonus` に追加）:
   - `crit20` 「急所狙い」: クリティカル率 +20%（クリティカル判定は `0.1 + masteryのcritAdd` に、パッシブのcritAddを加算。倍率は1.5のまま）。
   - `swift10` 「疾風」: 全スキルのCTを -1（最低1）。塔の `ctRed`・深淵の `ctAdd` と重ねがけでき、最低1を守る。
2. **汎用バフ**: 新しいバフスキルを、IDのハードコードなしで定義できるようにする。`SK` のバフに次のフィールドを持てる:
   `gen: { turns, atkMult?, defMult?, takenMult?, allMult? }`
   - `atkMult`: 攻撃力倍率、`defMult`: 防御力倍率、`takenMult`: 被ダメ倍率、`allMult`: 攻撃・防御（など）の全能力倍率。`turns` ターン持続（既存バフと同じカウント方法）。
   - 既存バフ（鉄壁・バーサーク・鬼神の構え等）の挙動は一切変えない。
   - ログは「◯◯！ 攻撃力が◯倍になった！」の形式で自動生成。
3. 回復スキルの `defTurns/defMult`、`regen`、`barrier` はそのまま使える。
4. BOT: `tools/bot.py` に、キャラ別の装備スキル（3枠）の優先リストを持たせる（初期案は §3 の各表の「BOT装備」）。

## 4. データ・実装の注意
- `src/data/skills.js` の `SK` に新スキルを追加。ツリーは `src/data/char_trees.js`（暫定の `// TODO(R1b)` を消す）。説明文 `desc` を全スキルに付ける。
- 新規スキルの演出は、R1b-1では**分類ごとの汎用演出にフォールバック**する（Q3の `SKILL_FX_MAP` に未登録でも動く）。ただし分類が分かるように、各スキルに仮の `cat`（slash/magic/ult/heal/buff）だけは `SKILL_FX_MAP` に登録する（演出は同分類の汎用のまま）。個別エフェクトはR1b-2。
- パッシブの表示名・説明は、既存のパッシブ表示（ツリー画面）に合わせる。
- 既存のスキル（旧キャラ構成）の数値・挙動は変えない。ステラのBOT結果が崩れないこと（参考: 495/498/509周、敗北10/7/25）。
- 新スキルの `ct` は `swift10` で最低1まで下がる。ログ・クールダウン表示（スロットのCT表示）が正しく出る。

## 5. 合格基準
1. 全4キャラのツリーの全マイルストーンが、定義済みのスキル/パッシブを指す（テストで総当たり。`id` の欠落なし）。暫定（TODO(R1b)）が残っていない。
2. 新スキル28個が `SK` に存在し、種類（atk/heal/buff）、ヒット数、倍率、MP、CT が §3 の初期案どおり。
3. `crit20` で、クリティカル率が+20%（テストで確率を統計的に確認、または計算式を直接確認）。`swift10` で全スキルのCTが-1（最低1）。
4. 汎用バフ（`gen`）が、攻撃力・防御・被ダメに反映され、ターン経過で切れる。既存バフ（鉄壁、鬼神の構え 等）の挙動は不変。
5. 4キャラともBOTが完走し（`--char`）、結果が出る（数値の合格はR1c）。ステラは参考値と大差ない（±帯: 周回490〜510、敗北≤30）。
6. セーブv9の移行（R1a）と、既存の全テスト・ビルド再現が通る。
