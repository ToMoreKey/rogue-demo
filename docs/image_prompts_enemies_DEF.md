# 敵画像プロンプト（ダンジョンD〜F、18枚）

Gemini（画像生成）に渡す。1ダンジョン＝1枚のシート（3列×2行、6体）。既存のA〜Cの敵シート（`enemy_sheet.png`相当）を**参照画像として添付**してから貼る。
出来上がったシートは、私（Claude）が背景を抜いて1体ずつ切り出し、`src/assets/enemy_images.js` に埋め込む。

配置の順番（左上→右下）と対応するID:

## 共通ルール（各プロンプトに含めてある）
- 添付した参照シートと同じ画風（ドット絵風、頭身の低いかわいい〜少し不気味なデザイン、太めの濃い輪郭、くっきりした陰影）。
- 1体ずつ全身、正面〜やや斜め。各セルの中央に、セルの高さの約80%で収める。ボスだけ他より一回り大きく、ほぼセル全体。
- 背景は単色のマゼンタ（#FF00FF）。体・装備・エフェクトにマゼンタ系（ピンク〜赤紫）を使わない。影・床・文字・枠線は入れない。
