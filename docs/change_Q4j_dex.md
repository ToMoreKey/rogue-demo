# Q4-4 5-B 図鑑・実績の見せ方
- **NEW バッジ**: 初めて見た敵・初入手の装備・達成直後の実績に「NEW」（`p.dexNew`、保存される）。図鑑を開いたタブ分は見た時点で消える。ステータスの図鑑ボタンに件数、図鑑のタブにドット。
- **発見演出**: 敵・装備の初登録でトースト「📖 図鑑に登録」。実績達成は画面中央のバナー（実績名・報酬・称号）。演出OFF/reduced-motion ではトースト。
- **コンプ率**: 全体（敵＋装備＋実績）の%、タブ別の進捗バー、実績はカテゴリ別バー、「あとN種で全種コンプ」。
- **フィルタ**: すべて/未達成のみ/達成済みのみ（敵・装備・実績）。並び替えは今回見送り（敵はダンジョン順、実績はカテゴリ順の既定のまま）。
- 未発見のシルエットと「？？？」・装備のヒントは既存のまま維持（終焉神ニヒルは遭遇まで「？？？」）。
