### 1. 見つかった問題（私の検証結果）

#### 問題A: 本編・回廊のBOT結果が、P5b-1 の前後で変わっている（「変えない」約束に反する）

| 項目 | P5b-1の前（94e692f） | P5b-1の後（26c7bc8） |
|---|---|---|
| 本編周回: ラン数 | 490〜493 | 486〜490 |
| 本編周回: `model_hours` | 20.85〜20.94 | 20.74〜20.88 |
| 本編周回: 1階あたりティック | 4.06〜4.13 | 3.47〜3.66 |
| 回廊（最適）の到達階 | 59 / 64 / 69 | 59 / 68 / 59 |
| 回廊（ランダム）の到達階 | 51 / 53 / 59 | 59 / 59 / 49 |

本編の1階あたりティックが約12〜15%下がっており、プレイヤーが強くなっている（または敵が弱くなっている）。極意・進化第3段階・深淵は、本編クリア後にしか関係しないはずなので、原因が分からない。

**原因の手がかり（私の推測。確認すること）**: `src/js/20_state.js` の `playerAtk` / `playerDef` が、`(p.mastery ? passiveBonus(p).atkMult : 1)` を掛けている。`newPlayer` が `mastery: {}`（空のオブジェクトで、真と評価される）を持つため、**極意を1つも振っていなくても常に `passiveBonus(p).atkMult / defMult` が掛かる**。`passiveBonus` の `atkMult` には、既存の剣15・戦士10・勇者10などの「攻撃力+◯%」パッシブが含まれる。これらが以前から別の場所で（例: ダメージ計算側で）すでに掛かっていた場合は**二重に掛かっている**。以前は掛かっていなかった場合は、本編のプレイヤーが急に強くなっている。

やること:
1. 原因を特定する。`git diff 94e692f 26c7bc8 -- src/` を調べ、本編のBOT結果が変わる原因をすべて挙げる（上の推測以外にも、`gearScore`（防具の評価式）、`armorDef`、`maxHp`/`maxMp` など、装備選択やステータスに触れた変更を確認する）。
2. **P5b-1 の前と全く同じ結果に戻す**。極意の効果は、**極意を振ったときの増分だけ**を加える（例: 極意専用の倍率 `masteryBonus(p)` を別に作り、`playerAtk`/`playerDef` などにはそれだけを掛ける。既存パッシブの効きを変えない）。
3. 戻した後、次を確認し、`docs/dev_notes_P5b1.md` に追記する:
   - 本編周回BOT（3シード）が P5b-1 の前と同じ（ラン数490〜493、`model_hours` 20.85〜20.94、1階あたりティック4.06〜4.13、Lv124）。
   - 回廊BOT（最適・ランダム × 3シード）が P5a修正後と同じ（最適59/64/69、ランダム51/53/59）。
   - ほかの `test_p1` 〜 `test_p5b1`、`test_save_migration` がすべて通る。ビルドが再現できる。
4. もし、P5b-1 の前の挙動が**不具合に見える**（例: パッシブの「攻撃力+◯%」が一度も効いていなかった）場合は、直さずに報告に「要確認」として書く（私が判断する）。

#### 問題B: 深淵の難度8〜10（強化ビルド）が易しすぎ、戦闘が間延びしている

`python3 tools/bot.py --mode abyss` の結果（3シード、強化ビルド）:
- 難度1〜9の初回クリア率がすべて100%、難度10だけ0%。難度9→10で急に壁になる。
- 難度8・9は50階で約900〜1,200ティック（1階あたり約18〜24ティック）。本編（1階あたり約4ティック）の5倍で、戦闘が間延びしている。

目標（標準ビルドは今のまま変えない: 難度1〜3が100%、難度4〜5が40〜60%、難度6〜10が0%）:
- **強化ビルド**（★8神話装備、極意を適度に振る、進化第3段階を取得）の初回クリア率:
  - 難度1〜5: 90〜100%
  - 難度6: 80〜95%、難度7: 60〜85%、難度8: 40〜65%、難度9: 20〜45%、**難度10: 5〜20%**（稀に勝てる）
  - 難度が上がるごとに、クリア率が単調に下がる（難度9→10の急な断崖をなくす）。
- 1階あたりのティックを、**本編の1.0〜2.0倍（4〜8ティック）**に抑える。難度8・9の長い戦闘の原因（敵のHPが高すぎる、呪い（ポーション効果・回復・スキルCT）で長引く、等）を調べ、敵の火力を上げてHPを下げる（戦闘は短く、一撃が重く）方向で調整する。
- 呪いの効果自体と、主の配置（難度3・6・10は強化版）は変えない。数値（難度ごとの敵ステータス倍率、`bossMult`）を調整する。

BOT の結果を、標準ビルド・強化ビルド × 3シード × 難度1〜10 の表で `docs/dev_notes_P5b1.md` に追記する。
