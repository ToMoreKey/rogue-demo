# 変更書: Q1（戦闘演出の品質アップ: ボス激昂の色味・スキル発動エフェクト）

## 1. 背景
運営者承認（2026-11-25）。見た目の品質向上。ゲームの数値・戦闘の進行・BOT結果は一切変えない（純粋な表示だけの変更）。

## 2. 変更A: ボス激昂（`o_boss_rage`）の演出
現状: O極級のボス「終焉神ニヒル」がHP50%以下で `o_boss_rage` に変わるが、見た目の変化が乏しい（画像未登録時は `o_boss` のドット絵を流用）。図鑑では `bossFilter: 'hue-rotate(140deg) saturate(1.6)'` で区別している。
- 戦闘画面でも、激昂中は敵スプライトに色味フィルター（図鑑と同じ系統の色。`hue-rotate`＋`saturate`）をかける。画像が専用に登録されている場合はフィルターを重ねない（二重に変色させない）。
- 激昂した瞬間（`40_game.js` の変化処理、行445付近）に1回だけの演出: 画面全体の赤い閃光（約300ms）、敵スプライトの拡大＋ぶれ、敵名の色変更。以後、激昂中は敵の周りに脈動するオーラ（赤〜紫の `box-shadow`/`drop-shadow` の緩い明滅。周期2秒程度）と、アリーナ周辺の薄い赤いビネット。
- 激昂が終わる（戦闘が終わる・敵が死ぬ）と、すべて自動で消える。次の戦闘に残らない。
- ログの専用メッセージ・攻撃力の変化は現状のまま。

## 3. 変更B: スキル発動エフェクト
現状: スキルを使うと、ログとダメージ数字だけで、通常攻撃との見た目の差がほとんどない。
アリーナ（`#arena`）の上に、クリックを邪魔しない演出レイヤー（`pointer-events:none`）を重ねる。**CSSとインラインSVG/DOMのみ**（画像・外部ライブラリの追加なし）。スキルを種類で分け、ID単位ではなく分類で演出する（全スキルIDを網羅し、未分類は「汎用」にフォールバック）。

| 分類 | 対象の目安 | 演出 |
|---|---|---|
| 斬撃（剣系） | 剣・戦士・英雄系の物理スキル | 敵の上を斜めに走る白〜金の斬撃線（多段ヒット数に合わせて本数が増える）。命中時に敵が一瞬白く光る |
| 魔法（攻撃魔法） | 魔法使い系の攻撃スキル | 敵の位置に広がる光の輪＋飛び散る光の粒。色は系統で変える（炎=橙、氷=水色、雷=黄、闇=紫、聖=白金。分からなければ青紫） |
| 大技・奥義 | 高倍率・多段・ボスに使う上位スキル | 画面全体の短い暗転→閃光、敵のぶれ（大）、強い斬撃/爆発。1戦闘で連発されても重くならない |
| 回復 | `type:'heal'` | プレイヤー側に緑の光の粒が上昇、回復数字と同期 |
| 強化（バフ） | `type:'buff'`、バリア・防御系 | プレイヤーの周りに色付きの輪（攻撃系=赤橙、防御系=青、全能力=金）が広がる。バフが続いている間は薄いオーラが残る（持続ターンが切れたら消える） |
| 汎用 | 上に当てはまらないもの | 控えめな光のフラッシュ |
- 演出の長さは約250〜600ms（大技は最大900ms）。ゲーム速度（`G.opts.speed`、1x/2x/…）が速いときは短く（速度に比例して詰める。最短150ms）。速度が速すぎて重なるときは、前の演出を即座に終わらせて次を出す（DOM要素が溜まらない）。
- 演出は表示のみ。`battleRound`・ダメージ計算・ログ・乱数・タイミング（setTimeout/tick）に**一切影響しない**。演出の失敗（例外）が戦闘を止めない（try/catchで隔離）。
- `prefers-reduced-motion: reduce` のときは、閃光・ぶれ・拡大を出さず、短いフェードの色表示だけにする。
- 画面の描画負荷を抑える: `transform`/`opacity` を中心に使う。同時に存在する演出要素は最大12個。小さい端末（360px）でも崩れない。
- 通常攻撃・クリティカルの既存表現は変えない（必要ならクリティカルの数字が少し目立つ程度の微調整は可）。

## 4. 設定
- ステータス画面「データ」タブに「戦闘エフェクト：ON/OFF」を置く（初期ON、`G.opts.fx` に保存。`opts` は既存のセーブ項目。値が無い古いセーブはONとして扱い、セーブ形式（v8）・マイグレーションは変えない）。OFFのときはA・Bの演出（色味フィルターは残してよい。閃光・ぶれ・レイヤー演出を出さない）。
- バトル中のログ・数字の表示は、設定に関わらず今まで通り。

## 5. 守ること
数値・バランス・BOT（本編/塔/深淵）の結果、セーブ形式(v8)、`to_dev` の分離、チュートリアルの動作を変えない。外部ライブラリ・画像を追加しない。仕様と矛盾する判断は勝手に決めず「要確認」と書く。

## 6. 合格基準
1. 激昂の瞬間と激昂中の演出が出る。戦闘終了後・次の戦闘で完全に消える（DOMとクラスが残らない）。
2. 全スキルIDが、いずれかの分類（または汎用）の演出になる（テストで全IDを走査）。分類ごとの代表スキルで、演出レイヤーに要素が出て、規定時間内に消える。
3. 演出の有無で、戦闘結果（同じ乱数での勝敗・ターン数・最終HP）が完全に一致する（エフェクトON/OFFで比較するテスト）。BOT結果は変わらない。
4. 高速（最大速度）で連続発動しても、演出要素が12個を超えない・溜まらない。ページエラーなし。
5. `prefers-reduced-motion` で激しい演出が出ない。OFF設定で出ない。設定が保持される。
6. 360/390/420px で崩れない（横スクロールなし、操作ボタンが隠れない）。
7. 全テストOK、ビルド再現、本編・塔・深淵のBOTが不変。
