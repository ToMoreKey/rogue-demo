## マージの手順（運営者）
1. 上の表がすべて埋まり、NGがないことを確認する。
2. GitHub で `dev` → `main` のプルリクエストを作り、内容を確認してマージする。
3. GitHub Pages の公開（数分）を待ち、公開URLを開いて、起動・戦闘・ランキング表示を確認する。
4. 問題があれば、`main` を前の状態に戻し（Revert）、`dev` で直す。
