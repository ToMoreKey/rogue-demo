### 0. 前提（これまでと同じ）
- `src/` を編集し、`python3 tools/build.py` で `index.html` を生成する。`index.html` を直接編集しない。
- `window.__rogue` と `window.G` を残す。外部ライブラリを追加しない。
- **`src/assets/` の画像データ（`enemy_images.js` `char_skins.js` `item_icons.js`）は触らない。** 敵画像は後で私が追加する。画像が無い敵は、ドット絵（`SHAPES` ＋ `PAL`）で表示される（既存の仕組み。`ENEMY_IMG[en.id]` が無ければドット絵）。
- 作業は `dev` ブランチ。`main` には push しない。push はこれまでと同じ方法（トークンは設定ファイルから読み、その場の変数で使い、画面・ログ・報告・ファイルに出さない。使用後に変数を破棄）。
- `index.html` を更新したら `sw.js` の `CACHE` のバージョンを上げる。
- 先に `docs/spec_volume_expansion.md`（特に3・4章と「時間の見積もりモデル」）と `docs/dev_notes_P1.md` を読む。仕様書の決定事項（8章）は変えない。

### 1. ゴール
ダンジョンD・E・Fを追加する（各5難易度＝新規15セル）。全体（A〜F、30セル）の人間の所要時間の見積もり（`model_hours`）が **約6.5〜7.5時間**になるよう調整する。データを足すだけで拡張できる設計を保ち、P3（G〜I）で同じ手順で足せるようにする。

### 2. やること

#### 2-1. ダンジョンD・E・Fのデータ追加（`src/data/dungeons.js`）
| ID | 名前 | テーマ | 色（`a1` / `a2` の例） |
|---|---|---|---|
| D | 古代樹の森 | 森・虫・精霊 | 深緑 `#14281a` / `#0c1a10` |
| E | 砂塵の遺跡 | 砂漠・ミイラ・古代装置 | 砂色 `#33281a` / `#211a10` |
| F | 水没神殿 | 水・深海生物・神官 | 青緑 `#103038` / `#0a2028` |

- 各ダンジョンに通常の敵5種＋ボス1種。IDと名前（画像を後で付けるので、**IDは変えない**）:
  - D: `d_mushroom` マッドマッシュ（`shape: slime`）、`d_moth` 毒蛾の群れ（`bat`）、`d_treant` 若木の番人（`skull`）、`d_beetle` 鎧甲虫（`skull`）、`d_dryad` 森の精霊（`bat`）、ボス `d_boss` 古樹の王ユグ
  - E: `e_scarab` スカラベ（`slime`）、`e_vulture` 砂漠コンドル（`bat`）、`e_mummy` ミイラ兵（`skull`）、`e_golem` 砂岩のゴーレム（`skull`）、`e_djinn` 砂塵の精霊（`bat`）、ボス `e_boss` 砂王ネフェル
  - F: `f_jelly` ディープジェリー（`slime`）、`f_piranha` 牙魚（`bat`）、`f_priest` 溺れた神官（`skull`）、`f_crab` 珊瑚蟹の戦士（`skull`）、`f_siren` セイレーン（`bat`）、ボス `f_boss` 深海王クラーケン
- 敵のステータス（`hp` `atk` `def` `exp` `gold`）は、C の値から自然に延長する（C→D→E→F で、同じ難易度ならわずかに強くなる）。
- 推奨レベル（`rec`、初級→極級）: D=`[24, 33, 44, 56, 68]`、E=`[30, 39, 50, 62, 72]`、F=`[36, 45, 55, 66, 76]`。
- `pow`・`DUNGEON_REWARD`・`expMult` などは、BOTで調整して決める。
- ドット絵の配色 `PAL` に D・E・F を追加する（既存の A〜C と同じ形式。テーマに合わせた色）。
- 超級・極級のボスの上位種表現、10階ごとの強敵は、既存の仕組みをそのまま使う。

#### 2-2. ダンジョンの解放（直前のダンジョンの上級クリアで解放）
- Dは「Cの上級クリア」、Eは「Dの上級クリア」、Fは「Eの上級クリア」で解放される。条件は `DUNGEONS` のデータで表す（P1 で用意した解放条件の仕組みを使う）。A〜Cは今までどおり最初から選べる。
- 未解放のダンジョンは、ダンジョン選択画面で「🔒 未解放（Cの上級クリアで解放）」のように示し、選べない。スマホ幅（420px）で崩れないこと。
- 既存セーブ（v3）の `cleared` の記録をそのまま使える。**セーブ形式を変えずに済む**のが望ましい（変える場合は、v3→v4 の移行処理とテストを追加する）。

#### 2-3. 装備ドロップ上限と★7の入手（決定事項）
- D〜F のドロップ上限は**★6**。★6は、ボスと10階ごとの強敵からのみ、低確率（目安: 5〜10%）で出る。雑魚・宝箱は★5まで。
- 強化素材「**時の欠片**」を追加する（`STONES`）。D・E・F のボス（超級・極級を含む）と、10階ごとの強敵からドロップする。**★6→★7の強化**に必要（`STONE_REQ`）。
- ★7の基礎値・名前は P1 で定義済みのもの（武器「時渡りの剣」ATK125、防具「雷霆の鎧」DEF62）を使う。強化できるようにして、ショップでは**売らない**。
- ★7のキャラ絵は★5の絵、アイコンは★5の流用＋「★7」のバッジ（★6と同じ方式）。
- 強化に必要なゴールド（`smithCost`）は、★3乗の式のまま。極端に高くならないか確認する。
- 所持品・ショップ・強化画面で、時の欠片が表示される（ストーンの一覧に追加）。

#### 2-4. スキルツリーの拡張（20SP→30SP）
- 剣・魔法・生命の各ツリーの `maxSp` を **30** にし、各ツリーに新スキルを3つ足す（`SK` `SK_ORDER` `SKILL_TREES.milestones`）。次を目安に、数値は既存スキルの伸びに合わせて調整してよい。
  - 剣（SP23／26／30）: 「烈火斬」（2回攻撃・各1.6倍・MP20・CT4）、「鬼神の構え」（4ターン攻撃力1.8倍・MP22・CT6。防御は下がらない）、「天翔斬」（7倍の一撃・MP40・CT7）
  - 魔法（SP23／26／30）: 「ブレイズ」（2.6倍・MP18・CT3）、「ライトニングストーム」（4回攻撃・各1.0倍・MP34・CT5）、「アルテマ」（9倍・MP55・CT8）
  - 生命（SP23／26／30）: 「ハイリジェネ」（3ターン、毎ターン最大HPの25%回復・MP14・CT4）、「ホーリーバリア」（5回無効化・MP18・CT6）、「聖女の祈り」（最大HP全回復・MP45・CT8）
- 既存のスキルポイントの割り振り（`skillPts`）は、そのまま使える。既存セーブで、割り振り済みの値が壊れないこと。
- スキルのUI（ツリー表示）が、30SPまでで崩れない。スキルスロット（装備できる数）は現状のまま。
- **進化枠の「第2段階」は、今回やらない**（P3で扱う）。

#### 2-5. BOT・バランス調整
- `tools/bot.py` が、A〜Fの全30セルを対象に動く。解放ルール（Dは Cの上級クリア後…）を考慮して、解放済みのセルから挑む。
- 新規の `pow`・`expNeed`（Lv56以降）・`expMult`・敵ステータス・`clearGold` などを調整する。`expNeed` はLv76付近まで自然に伸びる形にする（Lv99は上限としてエンド用に残す）。
- 時の欠片による★7強化、新スキルの習得、SP消費を、BOTが使う（余りゴールド・余りSPの測定のため）。

#### 2-4b. 合格基準（周回モード、3シードすべて）
1. 全30セルをクリアできる（`done: true`）。
2. `model_hours` が **6.5〜7.5時間**。ラン数は約140〜180（1セルあたり平均5ラン）。
3. 初回クリア率70%以上、敗北率15%以下。
4. 1階あたりの平均ティック数が、基準値3.50の **±25%以内**（手応えの維持）。
5. 終了時レベルが **Lv74〜78** 付近（Fの極級がrec 76）。
6. 余りゴールドが **0.5万〜10万G**。余りSPが少ない（使い切る設計）。
7. 「序盤の体感」を壊していない: 初級A 1ランの獲得ゴールド・薬1個・鍛冶★2→3の必要ラン数が、P1c の表（約119G／約1.7ラン／約1.9ラン）から大きく変わらない。
8. 既存のテスト（`test_p1.py` `test_save_migration.py`）がすべて通る。ビルドが再現できる。

#### 2-6. テスト（`tools/` に追加し、`README.md` に実行方法を書く）
- ダンジョンの解放: Cの上級未クリアでDに入れず、クリア後に入れる。E・Fも同様。
- ドロップ上限: D〜Fの雑魚・宝箱で★6以上が出ない。ボス・強敵からは★6が出る。C以前では★6が出ない。
- 時の欠片: D〜Fのボスからドロップし、★6→★7の強化に使える。ショップで売られていない。
- スキル: 新スキルが指定SPで習得でき、使える。20SP以下のセーブが壊れない。
- 敵IDが重複しない。`ENEMY_IMG` が無い敵がドット絵で表示され、エラーが出ない。
- セーブ移行（v1→最新、v2→最新、v3→最新）。
