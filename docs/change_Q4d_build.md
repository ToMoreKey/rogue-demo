# Q4-2E 複数ビルド・全ツリーリセット
- **ビルド**: キャラごとに最大3つ（`chars[cid].builds[]`＋`activeBuild`、枠数は `p.buildSlots`＝全キャラ共通）。ビルド＝各ツリーのSP振り分け＋装備スキル。装備・Lv・極意は共通。
- **ビルドの書**（ショップ）: 1冊目 5,000G／2冊目 60,000G（暫定）。
- **切替**: ステータス>スキル上部のタブ。街のみ・無料。名前は8文字まで変更可。戦闘力の増減は既存の通知・残像で表示。
- **SPの扱い（仕様からの変更点）**: SPは全キャラ共通プール（`p.sp`）のため、ビルド切替は「使用SPの差分」をプールと精算する方式にした。新ビルドは空で始まり、切替で今のビルドの使用SPがプールへ戻る。戻す側のビルドを再現するのにSPが足りない場合（極意などでプールを使った後）は切替不可で不足SPを表示。獲得SPはプールに入るため全ビルドで共通に使える。
- **全ツリーリセット**: 費用＝振っているツリー数×`skillResetCost`。2段階確認（1回目で費用とSP返還量を表示）。
- **保存**: SAVE_VERSION 10（v9→v10は buildSlots=0、現状＝ビルド1）。
