# 変更書: P8（セーブのバックアップ・引き継ぎ）

## 1. 背景
セーブはブラウザの `localStorage` にしかなく、端末の「サイトデータの消去」、容量整理、機種変更で消える。書き出し・引き継ぎの手段がない。運営者承認（2026-11-20、推奨案）。

## 2. 機能
### 2-1. 書き出し（設定画面。「初期化」ボタンの近く。初期化より目立たない位置にする）
- 「セーブを書き出す」: 次の2通りを選べる。
  - **ファイル**: `rogue-save-YYYYMMDD-HHMM.json` をダウンロードする。
  - **コード（文字列）**: クリップボードにコピーする（コピーできない環境では、選択状態のテキスト欄を表示する）。
- 書き出す内容: `{ app: 'rogue-demo', kind: 'save', saveVersion, exportedAt, data: <現在のセーブ（localStorage の文字列そのまま）> }`。
- コードは、`CompressionStream('deflate-raw')` が使えるときは圧縮して base64url にし、先頭に `RGS1:` を付ける。使えないときは圧縮なしで `RGS0:`。末尾に簡易チェックサムを付け、途中で切れたコードを検出できるようにする。
- 書き出したら、`最後に書き出した日時` を（セーブ本体ではなく別キーで）記録し、設定画面に表示する（未実施なら「まだ書き出していません」）。

### 2-2. 読み込み（設定画面）
- 「セーブを読み込む」: ファイルを選ぶ、またはコードを貼り付ける。
- 読み込み前に必ず検証する: 形式（`app`・`kind`）、`saveVersion` が現在以下、JSON として壊れていないか、チェックサム。**不正・壊れている場合は何も変更せず、理由を表示する。**
- 確認画面を出す: 「現在のセーブを置き換えます。レベル・所持ゴールド・進行状況（書き出し側と現在側）」を並べて見せ、「読み込む」を押したときだけ実行する。
- 実行前に、現在のセーブを別キー（`<SAVE_KEY>_bak_import`。直近1つだけ保持）に退避する。
- 読み込み後は、既存の `migrations`（v1〜最新）で最新形式に変換し、再描画する。古い版の書き出しも読み込める。
- 本番とテスト版（`/dev/`）はセーブのキーが別。**本番の書き出しをテスト版に読み込める**（その逆も可）。

### 2-3. 消えにくくする
- `navigator.storage.persist()` を、最初のユーザー操作のあとに1回だけ要求する（失敗・非対応は無視。ユーザーに表示しない）。
- セーブのたびに（連続保存は間引き、最短10秒間隔）、IndexedDB にも同じセーブを複製する。起動時に `localStorage` のセーブが無く、IndexedDB に複製がある場合は、**勝手に復元せず**「前回のデータが見つかりました。復元しますか？」を表示し、押したときだけ復元する（初回プレイヤーには出さない）。
- 本番とテスト版で IndexedDB のデータベース名も分ける（`tools/build.py` の `to_dev` で置換。`test_variants.py` に確認を追加）。

### 2-4. 控えめな案内
- 一度でもダンジョンをクリアしていて、最後の書き出しから7日以上たつ（または未実施）場合、起動時に**トーストで1回だけ**「セーブの書き出しをおすすめします（設定）」と出す。モーダルは出さない。同じ案内は7日に1回まで。

## 3. 守ること
- ゲームの数値・バランス・BOT結果は変えない。セーブ形式（バージョン）は変えない（書き出し用の別キーを足すのみ）。
- 外部への送信はしない（ファイルとクリップボードのみ）。トークン等の秘密情報を扱わない。
- 420px で崩れない。既存のテスト（`test_p1`〜最新、`test_save_migration`、`test_variants`、`test_noskip`）が OK。

## 4. 合格基準
1. 書き出し → 読み込みで、セーブが完全一致する（ファイル・コードの両方）。
2. 旧バージョン（v1〜v7）のセーブを書き出した形式も、読み込めて最新へ移行する。
3. 壊れたコード・別アプリのJSON・途中で切れたコード・未来の `saveVersion` で、何も変わらずエラー表示になる。
4. `localStorage` を消した状態で、IndexedDB から復元の確認が出て、押すと復元できる。初回プレイヤーには出ない。
5. 本番とテスト版でキー（localStorage・IndexedDB）が混ざらない。
