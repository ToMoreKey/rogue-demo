#### 2-2. ダンジョンの解放
- Gは「Fの上級クリア」、Hは「Gの上級クリア」、Iは「Hの上級クリア」で解放（`DUNGEONS` のデータで表す。P2と同じ仕組み）。未解放は「🔒 未解放（Fの上級クリアで解放）」のように表示する。
- セーブ形式は変えずに済むのが望ましい（変える場合は移行処理とテストを追加する）。

#### 2-3. 装備: ★7のドロップ・★8の追加・素材「機神の核」（決定事項）
- ドロップ上限: G・H は **★7**、I は **★8**。★7・★8は、ボスと10階ごとの強敵からのみ、低確率（目安: 5〜10%）。雑魚・宝箱は★5まで（D〜Fと同じ）。★6はG〜Iのボス・強敵からも出る。
- 強化素材「**機神の核**」（`stone_core`）を追加する。HとIのボス（超級・極級を含む）と、10階ごとの強敵からドロップ。**★7→★8の強化**に必要。ショップでは売らない。
- ★8を追加する。武器「魔王殺しの神剣」ATK190、防具「機神の鎧」DEF95。★8のキャラ絵は★5の絵、アイコンは★5の流用＋「★8」のバッジ（★6・★7と同じ方式）。
- ★9は今回やらない（P4）。ただし、データを足すだけで拡張できる構造を保つ（`WEAPON_BASE` などの配列延長で足せる）。
- `smithCost` は★3乗の式のまま。極端に高くならないか確認する。

#### 2-4. ★6以上のオーラ演出（新しい画像は使わない）
- 装備の★が6以上のとき、キャラの立ち絵（ステータス画面・戦闘画面）にオーラ（光る縁取り）を付ける。CSSの `filter: drop-shadow(...)` などで実装する。色は★6=金、★7=水色、★8=紫。武器・防具のうち高い方の★で決める（または防具の★）。仕様を1つ選んで、`docs/dev_notes_P3.md` に書く。
- スマホ幅（420px）でも、戦闘画面が重くならない・崩れない。

#### 2-5. 進化枠の第2段階
- 進化枠（戦士・魔術師・詠唱・英雄）の各ツリーは、現状 `maxSp: 10` で、最後のスキルは SP10 で習得する。**各ツリーを `maxSp: 20` に広げ、SP15 と SP20 で新スキルを1つずつ**足す（計8種）。次を目安に、数値は既存の伸びに合わせて調整してよい。
  - 戦士（バーサーク系）: SP15「修羅の構え」（4ターン攻撃力4倍・被ダメ1.2倍）、SP20「破軍の剣」（12倍の一撃）
  - 魔術師（ブリザード系）: SP15「アイスエイジ」（6倍・敵を凍らせる）、SP20「コズミックノヴァ」（14倍）
  - 詠唱（リザレクション系）: SP15「ホーリーライト」（最大HP全回復＋3ターン防御1.5倍）、SP20「レクイエム」（全回復＋MPも全回復）
  - 英雄: SP15「英雄の覚醒」（5ターン全ステータス2.5倍）、SP20「星剣の極意」（5回攻撃・各3倍）
- 第2段階の解放条件: 戦士は剣ツリーSP30、魔術師は魔法ツリーSP30、詠唱は生命ツリーSP30、英雄は3ツリーすべてSP30。それまでは、第1段階（SP10まで）のまま。
