## 2. 動作・連動仕様
- **タブバー**: `#view-status` 先頭に `.st-tabs`（`position: sticky; top: 0; background: var(--bg)`、5等分グリッド、最小高さ42px、`role="tablist"` / `role="tab"` / `aria-selected`）を配置。
- **状態保持**: `G.statusTab`（メモリのみ、初期値 `'hero'`、セーブ非保存）。再描画や他画面との往復、図鑑・実績モーダル開閉後も保持。タブ切り替え時は `#app.scrollTop = 0` にリセット。
- **SP通知ドット**: 未使用SP（`p.sp > 0`）があるとき「スキル」タブに `.st-dot` を表示し、本編クリア後（`p.ending && p.sp > 0`）は「極意」タブにも表示。
- **チュートリアル連動**: `step 4 -> 41`（ステータスタブ押下時）および `step 41` / `step 5` で自動的に `G.statusTab = 'skill'` に切り替え。クリア後お知らせモーダルの「見る」ボタンも極意→`mastery`、進化第3段階→`skill` に遷移。
- **390×844 スクリーンショット確認**: `tools/test_ui1.py` 実行時に `390×844` で5タブすべてのスクリーンショットを撮影し、5タブが1行に収まり、各タブで該当パネルのみが表示され、文字切れ・横溢れ（0px）がないことを確認。
- `sw.js`: `CACHE` を `'rogue-v36'` → `'rogue-v37'` に更新。
