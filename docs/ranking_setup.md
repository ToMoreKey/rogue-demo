# ランキングの準備と更新の手順（運営者向け）

方式: プレイヤーの記録が Googleフォーム に自動で送られる → スプレッドシートに溜まる → 運営者が確認して `data/ranking.json` を更新する（手動反映）。ゲームは `data/ranking.json` を読み込んで上位20位を表示する。

## A. 最初に1回だけ: Googleフォームを作る
1. Googleアカウントで https://forms.google.com を開き、「空白のフォーム」を作る。
2. 質問を**この順番で2つ**作る（種類はどちらも「記述式」）。
   - 1つ目: 質問名「ニックネーム」（必須）
   - 2つ目: 質問名「到達階」（必須）
3. 設定（歯車）→「回答」で、次を確認する。
   - 「メールアドレスを収集」: オフ
   - 「回答を1回に制限」: **オフ**（ログイン不要にするため）
   - 「回答者に回答の編集を許可」: オフ
4. 「回答」タブの緑の「スプレッドシートにリンク」を押し、新しいスプレッドシートを作る（回答が自動で溜まる）。
5. フォームの右上の「︙」→「事前入力したリンクを取得」を開く。
   - 「ニックネーム」に `AAA`、「到達階」に `123` と入力し、「リンクを取得」→「リンクをコピー」。
   - コピーしたURLを Claude に貼る（例: `https://docs.google.com/forms/d/e/1FAIpQLS.../viewform?usp=pp_url&entry.1111111=AAA&entry.2222222=123`）。
   - Claude が、ここから「送信先URL」と「質問のID（entry.数字）」を取り出し、ゲームの設定に入れる。

※ フォームのURLはゲームの中に入る（公開される）。このため、誰でも偽の記録を送れる。ランキングへの反映は運営者が確認してからなので、偽の記録が表に出ることはない。

## B. 運営者の更新手順（好きな頻度で）
1. スプレッドシートを開き、不審な行（異常に高い階、不適切な名前など）を確認する。消さなくてよい（次の手順で自動的に除外される）。
2. 「ファイル」→「ダウンロード」→「カンマ区切りの値（.csv）」で保存する。
3. CSVの中身を Claude に貼る（またはファイルを渡す）。Claude が `tools/make_ranking.py` で `data/ranking.json` を作り、`main` にコミットする。
   - 自分でやる場合: リポジトリで `python3 tools/make_ranking.py 回答.csv` を実行し、できた `data/ranking.json` をコミットして push する。
4. 除外のルール: 到達階が1〜500以外、ニックネームが12文字を超える・URLを含む・`tools/ranking_blocklist.txt` の語を含む記録は自動で除外する。同じニックネームは最高記録の1件だけ残す。
5. 不適切な名前を見つけたら、`tools/ranking_blocklist.txt` にその語を1行足して、もう一度作り直す。

## C. 注意
- ランキングに載るのは、ニックネーム・到達階・送信日だけ（個人情報は含まない）。
- ゲームは、ランキングを取得できなかったときは、前回取得した内容（端末内のキャッシュ）を表示する。
- 送信の可否はゲーム側から確認できないため、ゲームには「送信しました（反映まで時間がかかります）」と表示する。
