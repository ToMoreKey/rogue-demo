## 2. 判定の軽量化と保留コイン・セーブv7

- **イベント単位判定 (`checkAchievements(ev)`)**: `tick()` 内では一切走査せず、該当イベント（`run`, `kill`, `item`, `lv`, `sp`, `bless`, `gold`, `dex`）直後に当該カテゴリのみ判定。
- **本編クリア前のコイン保留 (`pendingAchCoins`)**: `!p.ending` 中に解除した実績コインは `p.pendingAchCoins` に加算し、虚空の神殿・極級クリア時（または移行読込時）に `flushPendingAchCoins(p)` で `p.tower.coins` へ一括付与。
- **セーブv7 (`SAVE_VERSION = 7`)**: `p.ach`（`{ [id]: 'YYYY-MM-DD' }`）、`p.pendingAchCoins`、`p.achStats`（`totalGold`, `blessings`, `noDmgBoss`）を追加。旧セーブ読み込み時に未判定の実績を一括判定・付与。
