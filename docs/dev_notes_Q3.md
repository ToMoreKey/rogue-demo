# 実装メモ: Q3（スキルエフェクトの個別化・格上げ）

## 1. 方針とティア設計
- **対象**: 斬撃（6種）・魔法（8種）・大技/奥義（8種）・回復（10種）の計32スキル。強化（バフ10種）は変更なし。
- **固有演出と一意の `sig` (signature)**:
  - `SKILL_FX_MAP` の各スキルに固有の `sig`、`tier`、`rank`、`durMs`（×1時の演出時間）、`nodes`（生成要素数）、`span`（演出が覆う代表サイズ px）を定義。
  - 32スキルすべてが異なる `sig` と異なるインラインSVG/DOM構造・アニメーション（落下・上昇・収束・回転魔法陣・横断斬撃・光柱・多重波紋など）を持つ。
- **ティア順序（同分類内での単調非減少＋最上位の豪華化）**:
  - 各分類内でティア（`rank`）が上がるほど、`durMs`（演出時間）・`nodes`（要素数）・`span`（覆う範囲）・閃光/ぶれの強さがいずれも下位以上（単調非減少）となり、最上位（`heroic`, `zeroAbs`, `genesisRay`, `eternal`）が最も豪華になるよう設計。
  - `docs/change_Q3_fx_variety.md` 3章のティア順序は、実データ（総倍率 `hits * mult`・MP・回復量・追加効果）とも整合しているため、表のティア割り当てをそのまま採用。
- **パフォーマンス・上限**:
  - 同時要素数の上限は **最大12個（`FX_MAX_NODES = 12`）のまま維持**（16個への引き上げ不要）。
  - 最大演出時間は `genesisRay`（創世の光）の `1180ms`（上限 `1200ms` 以内）。ゲーム速度 `G.opts.speed`（1x/2x/4x）に反比例して短縮（最短 `150ms`）。
