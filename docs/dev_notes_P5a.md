# P5a 開発メモ（無限回廊「天蓋の塔」・祝福30種・回廊コイン・交換所・称号）

## 1. 解放条件・階層の帯・スケーリング

- **解放条件**: `p.ending === true`（O 極級クリア後）。
- **敵の出現帯 (`TOWER_CFG.bands`)**:

| 階層 | 出現敵帯 (`DUNGEONS`) | 通常ドロップ上限 | ボスドロップ上限 |
|---|---|---|---|
| 1〜10F | A, B, C | ★4 | ★5 |
| 11〜20F | D, E, F | ★5 | ★6 |
| 21〜35F | G, H, I | ★5 | ★8 |
| 36〜50F | J, K, L | ★5 | ★8 |
| 51F〜 | M, N, O | ★5 | ★9（50F+ボス低確率4%） |

- 10階ごとにボス出現（接頭辞 `第N層の`）。50階ごとの節目ボスは O のボス（終焉神ニヒル、怒り形態なし）の上位種。
- **指数スケーリング**: `S = basePow * Math.pow(growth, floor - 1)`（`basePow = 2.2`, `growth = 1.062`）。回廊内では HP 倍率 `Math.pow(S, 0.45)`、ATK/DEF 倍率 `Math.pow(S, 1.02)` を使用。

## 2. 祝福・コイン・交換所・称号

- **祝福 (`TOWER_BLESSINGS`)**: 全 30種（純粋強化 12種 / 取引型 6種 / 成長型 6種 / 特殊 6種）。10階ごとのボス撃破で未取得からランダム 3択を提示、重複なし、ラン終了でリセット。
- **回廊コイン (`TOWER_CFG.coinsForFloor(floor)`)**:
  - `floor + Σ_{k=1..floor/10} (4 + 2k)`（50階以上到達時は 2倍）。例: 10F=16枚、30F=114枚、50F=200枚、59F=218枚。
- **交換所 (`TOWER_SHOP`)**:
  - `神話の魔王殺しの神剣`（★8 神話レア武器、ATK 190×6.0）: **300コイン**
  - `神話の機神の鎧`（★8 神話レア防具、DEF 95×6.0）: **300コイン**
  - ★9 神話装備は交換所に置かない（P5b の深淵ドロップ用）。
- **称号 (`TOWER_TITLES`, 全12種)**:
  - 到達階自動取得（6種）: `塔の挑戦者`(10F), `雲上の探索者`(20F), `塔の踏破者`(30F), `天蓋の覇者`(50F), `星界の征服者`(75F), `天を衝く者`(100F)
  - コイン購入（6種）: `黄金の収集家`(80), `神話の担い手`(150), `祝福を纏う者`(200), `無限の求道者`(350), `終焉を超えし者`(500), `天蓋の守護神`(800)

## 5. P5a 修正（壁の緩和・5F 2択祝福・効果強化・交換価格600コイン化）

- **スケーリング調整**:
  - `TOWER_CFG`: `basePow = 3.10`, `growth = 1.072`
  - ボス・節目の倍率: 回廊専用で `boss hp×1.85 / atk×0.90 / def×1.0`、`5F/15F...` は `hp×1.3 / atk×1.02` とし、60Fボスの急激な壁を緩和。
- **祝福の強化と5階2択の追加（方式 (a)）**:
  - 10階ごとのボス撃破（3択）に加え、**5階・15階・25階…の節目でも2択**を提示（50F到達時点で計10個取得でき、組み合わせの差が出やすい）。
  - 純粋強化（攻+25〜35% / 防+30〜45% / HP+35% / 与ダメ+30% / 被ダメ-25% 等）、取引型（背水+65%等）、成長型（10階ごと+10〜14%、50Fで純粋強化を上回る）、特殊（復活HP50%、吸収10%等）へ引き上げ。
- **交換所価格の見直し**:
  - ★8神話装備: 武器・防具 各 **600コイン**（50F前後を約3周で1つ交換可能）。
  - コイン購入称号: `200 / 400 / 700 / 1,100 / 1,600 / 2,400` コイン。
