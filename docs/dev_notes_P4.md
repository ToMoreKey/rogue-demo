## 2. レベル上限・経済・ドロップ・★9・神話レア

- **`LV_CAP`**: `99 → 140` に引き上げ（セーブ読み込みのクランプも `LV_CAP` 連動）。
- **`DUNGEON_REWARD`**: `{ A: 1, B: 1.35, C: 1.8, D: 0.45, E: 0.45, F: 0.45, G: 0.25, H: 0.25, I: 0.25, J〜O: 0.02 }`
- **`expNeed(lv)` / `DIFFS.expMult` / `clearGold`**: P2/P3 の式をそのまま継続（`lv >= 30` で `+0.015/Lv`、`lv >= 56` で `+0.022/Lv`）。
- **ドロップ上限**:
  - J〜O の通常ドロップ（雑魚・宝箱）は `maxStar: 5` まで。
  - J〜N のボス・強敵は `bossMaxStar: 8`（★8: 6% / ★7: 8% / ★6: 8%）。
  - O のボス・強敵は `bossMaxStar: 9`（★9: 極級 6%・それ以外 4% / ★8: 6% / ★7: 8% / ★6: 8%）。
- **創世の欠片 (`stone_genesis`)**: O のボスから 80%、強敵から 40% でドロップ（ショップ非売品）。`STONE_REQ[8] = 'stone_genesis'`。
- **★9装備・鍛冶**: `MAX_STAR = 9`、`SMITH_MAX_STAR = 9`。武器「創世の剣」(ATK 280)、防具「創世の鎧」(DEF 140)。`smithCost` は ★8→9 でコモン 14,336G〜レジェンド 50,176G。
- **★9オーラ (`.aura-9`)**: 虹色／プラチナ系 `drop-shadow` を追加。
- **神話レア (`rarity: 4`)**: `{ id: 'mythic', name: '神話', mult: 6.0, sell: 1200 }`、`PREFIX[4] = '神話の'` をデータと表示のみ追加（`rollRarity` / 鍛冶屋の祝福イベントからは出現しない）。

## 3. 最終ボス（O 極級）怒り状態と「ゲームクリア」

- **怒り状態**: O 極級の `o_boss`（終焉神ニヒル）が HP 50% 以下になった時点で、HPを引き継いだまま `o_boss_rage`（終焉神ニヒル・真）へ変化し、`atk = Math.round(atk * 1.35)`、専用ログと攻撃メッセージに切り替わる（`o_boss_rage` の画像未設定時は `o_boss` へフォールバック）。
- **ゲームクリア演出**: O 極級の初回クリア時に1回だけモーダル表示し、`p.ending = true` を保存（既クリアセーブでは再表示しない）。

## 4. SP 総量の確認結果（Lv140上限）

- 全7スキルツリーの上限合計は `30×3 + 20×4 = 170 SP`。
