# UI-3: ダンジョン背景・ダンジョンタブの区切り・戦利品比較・戦力表示（Claudeが実装）

運営者要望（2026-11-26）: ①各マップが黒背景で素朴 ②ダンジョンタブにダンジョンごとの区切りがなくわかりにくい ③クリア後にドロップが現在の装備より強いか弱いかを（現在の装備の値も）わかるように ④レベルや装備の更新で明確に強くなったとわかるように。

## 実装
1. **背景シーン**（`src/js/62_scenes.js`）: 15ダンジョン＋塔(T)＋深淵(Y)の17枚をインラインSVG（400×160）で描画。地下墓地の墓石、火山の溶岩と岩、氷晶、古代樹の森、砂漠の遺跡と月、水没神殿の柱、空中庭園の稲妻、機巧の歯車、魔王城と赤い月、湿原の鬼火、水晶の鉱脈、大聖堂のステンドグラス、天文台と星空、竜骨の渓谷、虚空の裂け目、塔、深淵の目。データURI（`sceneUri(id)`、`url('…')`＝style属性内でも使える形）。戦闘アリーナ（`--scene`）とダンジョンカードのバナーで共用。文字の可読性のため暗めの重ねグラデーション。
2. **ダンジョンタブ**: 各カードにバナー（シーン背景＋敵スプライト＋頭文字バッジ＋ダンジョン名）とダンジョンごとのアクセント色の上線。「前編 魔王城への道（A〜I）」「後編 真の黒幕との戦い（J〜O）」「エンドコンテンツ（塔・深淵）」の見出しで区切り、カード間の余白を拡大。未解放カードは彩度を落とす。全難易度踏破でバナーに「✓全難易度踏破」。
3. **戦利品の比較**（結果画面・通常/塔）: 各ドロップに「現在（または出撃前）の装備名・攻撃力/防御力」と「これ」の値を並べ、`▲強い/▼弱い/＝同等　±差（±%）`を表示（判定は `gearScore`、数値は特性込みの `gearPower`）。自動装備された戦利品は、自動装備前（出撃前）の装備と比較し「✔装備中」を表示。上位（強い順）に並べ替え。バッグにある戦利品には「この装備に変更」ボタン（`mEquip`）で結果画面から装備変更でき、比較は更新される（スクロール位置は維持）。
4. **強くなった表示**:
   - 総合戦力 `playerPower = 攻撃力＋防御力＋最大HP/8＋最大MP/20`（表示専用、戦闘計算に不使用）。HUDのLv横に「戦力 N」チップ。
   - 装備変更・鍛冶・スキル割り振り/リセット・極意で戦力が変わると、チップが光り「▲ +n」が浮かび、「戦力 A → B（+n）▲ 強くなった！」とトースト（戦闘中は出さない）。
   - 結果画面に「出撃前→現在」の成長パネル（総合戦力・Lv・攻撃力・防御力・最大HP・最大MP・武器/防具の変更）。変化がなければ強化のヒントを表示。
5. **テスト**: `tools/test_ui3.py`（17シーンの固有性・実描画、区切り見出し、360px横スクロールなし、アリーナ背景、比較の強/弱/同等と自動装備時の「出撃前」比較、結果画面からの装備変更、HUD戦力と通知）。`test_r1b` の berserk テストは乱数を固定して安定化。sw `rogue-v51`。

- パネル・チップ・下タブ・施設ボタンを青紫グラデ＋画面色のアクセント枠に。バナーのオーバーレイを薄くし発光を追加。sw は `rogue-v53`。
