## 2. 総SP量と余りSPの使い道（進化第3段階 + 極意）

- **Lv140時点の獲得総SP**: 初期`3` + Lvアップ`139` + 初回踏破`135` (`15×9`) = **277 SP**。
- **消費総SP**: 基礎3枠(`90`) + 進化第1〜2(`80`) + 進化第3(`40`) + 極意10種(`110`) = **320 SP**（獲得総SPの **115.5%**）。
- **進化第3段階（`p.ending`後解放、SP21〜30）**:
  - 戦士: `tenma`(SP25, 18倍), `kishin`(SP30, 5T攻5倍・被ダメ1.1倍)
  - 魔術師: `zeroAbs`(SP25, 9倍+凍結2T), `meteorNova`(SP30, 22倍)
  - 詠唱: `goddess`(SP25, HP/MP全回復+4T防2倍), `eternal`(SP30, 全回復+5T35%再生+3回バリア)
  - 英雄: `heroAdvent`(SP22, 6T全能力3.5倍), `skyStar`(SP26, 4倍×6回), `genesisRay`(SP30, 24倍)
- **極意 (`MASTERY_LIST`, 10種, 最大Lv10)**: 各Lv1〜9=`1SP`、Lv10=`2SP`（1項目11SP×10=110SP）。項目: 攻撃+1.5%、防御+1.5%、最大HP+2%、最大MP+2%、会心率+0.8%、与ダメ+1.5%、被ダメ-1%、回復+2%、EXP+2%、Gold+2% / ランク。

## 3. ★9神話装備・複数特性（`it.props`）・再鍛造

- **特性数分布（重複なし）**: 武器 0〜3個（15% / 40% / 30% / 15%）、防具 0〜2個（30% / 45% / 25%）。
- **防具用特性 (`ARMOR_PROPS`)**: `aegis`(防具DEF1.15倍), `ward`(被ダメ-10%), `thorns`(被ダメの15%反射), `regen`(毎T最大HP3%回復)。
- **戦力値 (`gearPower`) / 評価式 (`gearScore`)**:
  - `gearPower`: 武器は各特性 `atkMult` の積、防具は各特性 `defMult` の積で実効値表示。
  - `gearScore`: 狂気(`madness`)を含む武器は自動装備・おすすめから除外。複数特性武器は `flame=1.2, vamp=1.05` の積、防具は `armorDef * (1 + 非aegis特性数 * 0.08)`。
- **再鍛造**: ★9神話ドロップ品（武器・防具両方可）は再鍛造で特性数と内容を一括振り直し。

## 5. P5b-1 修正（問題A・問題B）

- **問題A（本編・回廊BOTの復元）**:
  - 原因1: `passiveBonus(p)` に極意を同居させ、`playerAtk` / `useSkillEffect` から呼んだため、従来未適用だった既存パッシブ（`sword15`/`warrior10`/`hero10` の `atkMult` と `cleric10` の `healMult`）が本編・回廊で新たに発動していた。
  - 原因2: `tools/bot.py` の `tower` モードで `p.weapon.prop = 'flame'` のみを上書きし `p.weapon.props` を更新していなかったため、`genItem` がランダム付与した `props` が残っていた。
  - 対処: 極意専用の `masteryBonus(p)` を新設して `passiveBonus(p)` を `94e692f` 同一に戻し、`bot.py` の `p.weapon.props = ['flame']` を明示。
  - 復元確認（3シード）: 本編周回 ラン数 `491/490/493`、`model_hours` `20.9/20.85/20.94`、1階あたり `4.06/4.13/4.06`、Lv `124`。回廊 最適 `59/64/69`、ランダム `51/53/59`（`94e692f` と完全一致）。
- **問題B（深淵難度6〜10の再調整）**:
  - `pow` の急騰による敵HP膨張（18〜24ティック/階）を解消するため、`ABYSS_CFG.diffs` に難度別の `hpMult`（0.90→0.65）と `atkMult`（5.80→3.15）を追加し、「敵HPを抑えて高火力・短期決戦（3.1〜5.7ティック/階）」へ調整。
  - 強化ビルドのクリア率は難度1〜5 `100%` → 6 `87%` → 7 `80%` → 8 `60%` → 9 `40%` → 10 `13%` と単調減少。
