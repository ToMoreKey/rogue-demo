# 変更書: Q2（テスト版のエフェクト確認パネル）

## 1. 目的
運営者要望（2026-11-25）。テスト版（`/dev/`）に、スキルのエフェクトを好きなだけ確認できるデバッグ機能を置く。ボタンを押すとそのスキルの演出が出る。本番では出ない。

## 2. 仕様
- ステータス画面「データ」タブの、既存のテスト用ボタンの並び（`IS_DEV_BUILD` のときだけ出るもの）に「🎬 エフェクト確認」ボタンを追加。押すと、全画面のモーダル（`.sheet`、閉じるボタン付き）を開く。**`IS_DEV_BUILD === false`（本番）では、ボタンもモーダルも出ない・開けない**（`openFxDebug` 等の入口は `IS_DEV_BUILD` で弾く）。
- モーダル内の構成:
  1. **確認用アリーナ**（上部、sticky）: 勇者と敵（初期は雑魚、切替で O のボス）が並ぶ、戦闘画面と同じ見た目のミニアリーナ。実戦闘と**同じ演出コード**（`playSkillFx`、激昂演出、バフオーラ）を使う。実戦闘のDOM（`#arena`・`#fx-layer`・`#f-enemy` など）とIDが衝突しないこと（演出関数がIDを直接参照しているなら、対象ルート要素を引数/文脈で渡せるように最小限リファクタする。実戦闘の挙動は変えない）。
  2. **スキルボタン一覧**: 分類（斬撃／魔法／大技／回復／強化）ごとに見出し、その下に全スキルのボタン（スキル名表示）。押すと確認用アリーナで、そのスキルの演出を再生（斬撃・魔法・大技は敵に、回復・強化は勇者に出る。多段ヒットは本来のヒット数で）。連打可能（前の演出を即終了して次を出す＝実戦闘と同じ仕様）。
  3. **操作**: 「速度 ×1/×2/×4」（演出時間の確認用。実戦闘の `G.opts.speed` を書き換えず、確認用のみ）、「激昂表示 ON/OFF」（激昂の色味・オーラ・ビネットの確認）、「激昂の瞬間を再生」（閃光＋拡大）、「バフオーラ 攻撃／防御／全能力／なし」、「敵の切替（雑魚／ボス・激昂用）」、「演出を止める」。
- 戦闘エフェクトの設定が OFF でも、このパネルでは確認できるよう、パネル内の再生は設定を無視して出す（`prefers-reduced-motion` は尊重し、その場合は短い注記を表示）。
- ゲームの状態・セーブに一切影響しない（`G.p`、`G.run`、ゴールド、アイテム、乱数、タイマーを触らない。確認用アリーナは表示専用の仮の値だけを使う）。モーダルを閉じたら演出要素・クラス・タイマーを完全に消す。

## 3. 守ること
本番ビルドに出さない（`to_dev` の分離方針と同じ。`index.html` の本番出力で入口が到達不能で、`dev-badge` 等の dev 文字列を本番に混ぜない）。数値・バランス・BOT・セーブ形式(v8)を変えない。外部ライブラリ・画像を追加しない。実戦闘の演出（Q1）の見た目と挙動を変えない。

## 4. 合格基準
1. dev ビルドで「データ」タブにボタンが出て、モーダルが開閉できる。本番ビルドには出ない（`test_variants` 相当で確認）。
2. 全スキルIDのボタンが並び、分類に漏れ・重複がない。各ボタンで演出レイヤーに要素が出て、規定時間内に消える。
3. 速度・激昂・バフオーラ・敵切替・停止が動く。連打しても要素が12個を超えない。
4. モーダルの操作の前後で `G.p`・`G.run`・セーブデータ（`localStorage`）が変わらない。閉じたら演出が全部消える。
5. 360/390/420px で、確認用アリーナが見えたままボタン一覧をスクロールでき、崩れない。ページエラーなし。
6. 全テストOK、ビルド再現、BOT結果不変。
