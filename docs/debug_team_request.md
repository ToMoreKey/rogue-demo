# デバッグ部隊への依頼書（通しプレイ）

ご協力ありがとうございます。ブラウザで遊ぶローグライクRPG「rogue-demo」の、本編クリアからやり込み要素までの通しプレイをお願いします。**数値バランスの体感**と**不具合**を知るのが目的です。

## 1. 遊ぶもの
- テスト版URL: https://tomorekey.github.io/rogue-demo/dev/ （画面の右上に「TEST版」と出ます）
- 推奨環境: スマホ（Android Chrome）またはPCのブラウザ。縦画面。
- セーブはブラウザ内に保存されます。同じ端末・同じブラウザで遊んでください。シークレットウィンドウは使わないでください。

## 2. お願いしたいプレイ
1. **本編**: 新規で始め、ダンジョンA〜Oを順に進め、最後のボス（終焉神ニヒル）を倒すまで。目安 約20時間（倍速を使ってよい）。
2. **クリア後**: 天蓋の塔（回廊）で到達階を伸ばす。回廊コインで装備・称号を交換する。
3. **深淵**: 解放されたら、難度1から順に挑戦する（全部クリアしなくてよい）。
4. **途中の気づき**: 詰まった所、退屈な所、強すぎ・弱すぎる物を、その場でメモしてください。

## 3. 報告してほしいこと（コピーして回答してください）
- 進行: どこまで進めたか／総プレイ時間／使った倍速
- 詰まった箇所: ダンジョン名・階層・敗北回数・何で突破したか
- 退屈・作業感のあった所（周回が長い、SPやゴールドが余る・足りない）
- 強すぎ・弱すぎる装備、スキル、パッシブ、特性、祝福、極意
- ボス（特に終焉神ニヒル、深淵の主）の体感（簡単／ちょうど良い／厳しい）
- 回廊: 到達階、祝福の選び方、回廊コインの貯まり方
- 深淵: 挑戦した難度と結果
- 不具合: 画面・操作・手順（できればスクリーンショット）。数値の不満と区別して書いてください。
- ランキング: 同意して送信した場合、送信できたか（ニックネームは仮のもので構いません）

## 4. ご注意
- ランキングの送信は、同意した場合だけ行われます。テスト用のニックネームを使ってください。
- 個人情報は入力しないでください。
- 感想は「つまらない」でも歓迎です。どこで、なぜ、を一言添えてもらえると助かります。
