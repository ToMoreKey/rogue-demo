# 不具合報告（ゲーム内）の設定と運用

プレイヤーがゲーム内から報告 → Google フォーム → スプレッドシートに溜まる → CSV を私（Claude）に渡す → 対策リストにまとめて修正、の流れ。ランキングと同じ方式で、サーバーもトークンも使わない。

## A. 最初に1回だけ: Googleフォームを作る（ランキングとは別のフォーム）
1. Googleアカウントで https://forms.google.com を開き、「空白のフォーム」を作る。名前は「rogue 不具合報告」など。
2. 質問を**この順番で3つ**作る。種類はすべて「段落」（長文）。**必須にはしない**。
   - 1つ目: 質問名「種類」
   - 2つ目: 質問名「内容」
   - 3つ目: 質問名「診断情報」
3. 設定（歯車）→「回答」で、次を確認する。
   - 「メールアドレスを収集」: オフ
   - 「回答を1回に制限」: **オフ**（ログイン不要にするため）
   - 「回答者に回答の編集を許可」: オフ
4. 「回答」タブの緑の「スプレッドシートにリンク」を押し、新しいスプレッドシートを作る。
5. フォームの右上の「︙」→「事前入力したリンクを取得」を開く。
   - 「種類」に `AAA`、「内容」に `BBB`、「診断情報」に `CCC` と入力し、「リンクを取得」→「リンクをコピー」。
   - コピーしたURLを Claude に貼る（例: `https://docs.google.com/forms/d/e/1FAIpQLS.../viewform?usp=pp_url&entry.111=AAA&entry.222=BBB&entry.333=CCC`）。
   - Claude が、ここから「送信先URL」と「質問のID（entry.数字）」を取り出し、ゲームの設定（`src/data/bugreport.js`）に入れる。

※ フォームのURLはゲームの中に入る（公開される）。誰でも送れるため、迷惑な投稿が入る可能性がある。集計ツールが除外する。

## B. 運営者の更新手順（好きな頻度で）
1. フォームの「回答」→ スプレッドシートを開く →「ファイル」→「ダウンロード」→「カンマ区切りの値（.csv）」。
2. そのCSVを Claude に渡す（添付）。
3. Claude が `python3 tools/make_bug_report.py 回答.csv` で集計し、`docs/bug_triage.md`（対策リスト）を作る。
4. 採用する項目を決めて、まとめて修正 → テスト版（/dev/）で確認 → 公開。
5. 処理した報告は、スプレッドシートの「処理済み」列（自分で追加してよい）や、新しいシートに移すなどで区別する。CSV に残っていても、集計ツールは前回までの分を `data/bug_seen.json` で覚えて重複を除く。

## C. 注意
- 本番とテスト版は、診断情報の「ビルド」欄（`prod` / `dev`）で区別できる。テスト版からの報告は、`make_bug_report.py` の既定で別表にする。
- 診断情報は、版・画面サイズ・ブラウザの種類・現在のレベルと場所・直近の画面エラーだけ。**セーブデータ、ニックネーム、個人情報は送らない。**
- スクリーンショットは添付できない（Google フォームのファイル添付にはログインが必要なため）。説明文に、どの画面で何を押したかを書いてもらう。
