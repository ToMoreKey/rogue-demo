# 実装メモ: R1b-1（キャラ専用スキルのデータ・仕組み）

実装: Claude（Geminiのクレジット切れのため、運営者了承のうえ私が実装）。仕様: `docs/change_R1b_new_skills.md`。

## 変更点
- **新パッシブ**（`passiveBonus`、`src/js/10_art.js`）: `crit20`（`critAdd +0.20`）、`swift10`（`ctRed +1`）。クリティカル判定は `0.1 + masteryのcritAdd + パッシブのcritAdd`、CT設定は `max(1, ct - 塔ctRed + 深淵ctAdd - パッシブctRed)`（`playerAct` と `useSkillEffect` の2箇所）。
- **汎用バフ**（`src/js/40_game.js`）: `SK.gen = { turns, atkMult?, defMult?, takenMult?, allMult? }`。`run.gen` に保持（1枠、再使用で上書き）。`genBuffMult(run, 'atk'|'def'|'taken')` を攻撃力・防御力・被ダメ計算に掛ける。ターンは**敵の攻撃ごとに1減る**（鬼神の構え・修羅の構えと同じ数え方）。既存バフのコードは未変更。バフ中のオーラ表示（`syncBuffAura`）も `gen` に対応。
- **新規スキル27個**（`src/data/skills.js`）: クロエ15、ステラ1（剣神の一閃）、ルビィ4、シリア7。仕様書は「28個」としていたが、シリアの最終奥義は既存の創世の光のため実数は27（シリア8→7）。`SK_ORDER` にも追加（装備UI・エフェクト確認パネルに必須）。
- **ツリー**（`src/data/char_trees.js`）: 4キャラ×3ツリーを本設計に差し替え。`// TODO(R1b)` は全て解消。ステラ奥義30SP=剣神の一閃、ルビィ奥義=大魔導（大魔導の奇跡・星屑の極意・蒼穹の流星群・終焉の大魔法）、シリア=主に聖光弾(5)・聖裁(13)・聖なる爆光(28)、第2に神罰(22)、奥義=聖女（天使の奇跡・聖槍の極意・蒼穹の聖星・創世の光）、クロエ=全て新規（盗技・怪盗・大怪盗）。
- **演出**（`src/js/60_render.js`）: 新スキルを `SKILL_FX_MAP` に登録（`proc: true`）。R1b-1は**手続き型の共通演出**（分類・ティア別のノード数/長さ/範囲。DOMは `sig-<id>` クラスでスキルごとに異なる）。個別のモチーフはR1b-2。Q3のティア順序・一意性・要素数上限のテストは通る。
- **BOT**: `order`/`buff` リストに新スキルを威力順で追加。キャラ別の装備は、現キャラが持つスキルから自動選択（これまでと同じ「回復or強化1枠＋攻撃2枠」ロジック）。
- **`__rogue` に公開**: `playerAct, enemyAct, useSkillEffect, genBuffMult`（テスト用）。
- **表示文**: 英雄の奇跡の説明を実挙動に合わせた（「全ステータス2倍で3回攻撃」→「3回攻撃（各3倍」）。実際には全ステータス2倍の処理は存在しなかった。
- **テスト更新**: `test_p5b1`（ステラの最終スキルが剣神の一閃）、`test_q3`（バフ数は10以上）。判定は弱めていない。新規 `test_r1b.py`。

## 発見した既存の仕様（要検討）
- **バーサーク（berserk）**: ログとオーラはあるが、`攻撃3倍・防御半減` の処理が戦闘計算に存在しない（効果なし）。クロエの「狂乱の刃」は同等の位置づけだが、汎用バフで**実際に効く**ため、ステラのバーサークより強くなる。R1cで、①バーサークを実装する、②狂乱の刃を弱める、のどちらかで揃える（BOT基準が変わるため運営者判断）。
- 英雄の奇跡の「全ステータス2倍」も同様に未実装だった（説明のみ修正）。
