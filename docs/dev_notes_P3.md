## 3. オーラ演出の仕様（★6以上）

- **判定基準**: 装備中の武器・防具のうち**高い方の★**で決定（`Math.max(weapon.star, armor.star)`）。
- **表示方法**: ステータス画面・戦闘画面のキャラ立ち絵（`skinArt()`）に CSS `filter: drop-shadow(...)` クラスを付与。
  - ★6: `.aura-6`（金 `#ffd45a`）
  - ★7: `.aura-7`（水色 `#6de7ff`）
  - ★8: `.aura-8`（紫 `#c56bff`）
