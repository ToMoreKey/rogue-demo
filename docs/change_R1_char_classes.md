# 変更書（案）: R1（キャラごとのスキル・パッシブ分け）

状態: **案。運営者の確認前。Geminiには渡さない。**
運営者方針（2026-11-25）: 4キャラ（ルビィ=魔法使い、ステラ=剣士、シリア=聖職者、クロエ=盗賊）で、取得できるスキル・パッシブを分け、組み合わせを制限する。**どのキャラでも、そのキャラだけで最終ダンジョン（O極級）までクリアできること**。
運営者の選択: ①キャラごとに独立して育成（切替は自由）、②クロエは専用ツリーを新規作成、③既存セーブは全SPを返却して振り直し。

## 1. 基本ルール
- 現在選んでいるキャラ（既存の `p.skin`）が、**戦闘で使えるスキル・パッシブを決める**。ほかのキャラに振ったスキルは使えない（キャラを切り替えると、そのキャラのスキルセットに切り替わる）。
- **SPは全キャラ共通のプール**（レベルアップ・初クリアで増える。今と同じ量）。各キャラのスキルツリーに振り分ける。ツリーごとの「振り直し」（SP返却）は今の機能をそのまま使う（無料）。
- レベル・装備・ゴールド・図鑑・実績・塔・深淵・極意は**全キャラ共通**（キャラを替えても失われない）。
- スロット（装備スキル3枠）は**キャラごとに別々**に保存する。
- キャラの切替は、街・ステータス画面でいつでも可能。**ダンジョン攻略中（ラン中）は切替不可**。
- 最終的に、1キャラのスキルを全部取っても最後までクリアできる（SP総量で足りることを確認する。§5）。

## 3. キャラごとのツリー構成（初期案）
各キャラ **3ツリー×各30SP＝90SP**。第2ツリーは主ツリー10で解放、第3（奥義）ツリーは「主20かつ第2が20」で解放（今の戦士・英雄枠の解放の考え方を踏襲）。
**自己回復の最低ライン**: 非ヒーラー（ステラ・ルビィ・クロエ）の主ツリーに、ヒール/リジェネ相当を1〜2個入れる（回復だけで戦えないが、薬に頼り切らなくても進める）。

### ステラ（剣士）
- 主「剣技」: 現在の剣枠（強撃・鉄壁・連続斬り・攻撃力+15%・必殺剣・烈火斬・鬼神の構え・天翔斬）。ここに **ヒール**を追加（3SP枠のどこかと差し替え。候補: 強撃を3、ヒールを6、鉄壁を8…のように詰め直す）。
- 第2「戦士」: 現在の戦士枠（バーサーク・攻撃力+30%・修羅の構え・破軍の剣・天魔滅殺斬・鬼神降臨）。
- 奥義「剣聖」: 英雄の奇跡・全能力+25%・英雄の覚醒・星剣の極意・勇者の光臨・蒼穹星剣、30SPの最終技は**新規**（剣系、24倍級、仮名「剣神の一閃」）。

### ルビィ（魔法使い）
- 主「魔法」: 現在の魔法枠（ファイアボール・マジックシールド・サンダー・MP最大+20%・メテオ・ブレイズ・ライトニングストーム・アルテマ）。ヒールを追加。
- 第2「魔術師」: 現在の魔術師枠（ブリザード・MP消費-20%・アイスエイジ・コズミックノヴァ・絶対零度・メテオノヴァ）。
- 奥義「大魔導」: 全能力+25%相当・魔法系の奥義（新規。英雄の奇跡・星剣系の魔法版を2〜3個、最終技は24倍級の魔法、仮名「終焉の大魔法」）。

### シリア（聖職者）
- 主「生命」: 現在の生命枠（ヒール・リジェネ・バリア・HP+20%・フルヒール・ハイリジェネ・ホーリーバリア・聖女の祈り）。**攻撃スキルが皆無**なので、「ホーリー系の攻撃」（新規、3〜4個、倍率は低め・回復と併用前提）を第3ツリーまたは主に入れる。
- 第2「詠唱」: 現在の詠唱枠（リザレクション・回復+50%・ホーリーライト・レクイエム・女神の奇跡・永劫の祈り）。
- 奥義「聖女」: 創世の光（天からの聖光、24倍）・全能力+25%相当・勇者の光臨相当の聖なる強化、ほか聖属性の攻撃（新規を含む）。

### クロエ（盗賊）— 全て新規（名前は仮）
- 主「盗技」: ダブルスタブ（2回×約1.1倍）、影走り（防御バフ）、ラッシュ（4回×約0.7倍）、**クリティカル率+（新パッシブ）**、連刃乱舞（6回×約0.7倍）、疾風の構え（攻撃バフ）、リジェネ相当の自己回復、最終は高倍率の単発（約7倍）。
- 第2「怪盗」: 低CT化（全スキルのCT-1。新パッシブ）・高回数の多段・ゴールド獲得+（新パッシブ。要検討：経済に影響するため入れるなら控えめ）・大技。

- 新しい仕組み（クリティカル率、CT短縮）は、戦闘計算の変更を伴う。クリティカルは既存の仕組みがあるので、その確率を上げる形にする。

## 4. 実装の概要（承認後にGeminiへ）
- セーブ形式 **v9**（マイグレーション付き）: `p.chars[id] = { skillPts, equippedSkills }`。`p.passiveSkills` は**現キャラの習得済みパッシブから都度計算**する。`p.skin` は現キャラ（外見＋職）。**既存セーブ**: 全SPを返却（`p.sp` に加算）、スキル・スロット・パッシブをリセット、「システムが変わりました」の案内を1回表示。v8のバックアップを自動で残す（既存の仕組み）。
- ステータス画面の「スキル」タブ: 現キャラのツリーだけ表示。キャラ切替ボタン（ラン中は無効）を勇者タブの外見変更の近くに置く（外見変更を「キャラ変更」に統合）。
- 塔・深淵・極意・図鑑・実績・ランキング: 共通のまま。キャラは影響しない（ただし塔の祝福は、パッシブの組み合わせで強さが変わるためBOTで確認）。
- チュートリアル: 序盤のスキル習得の案内を、現キャラ（初期は選択済みのキャラ）のツリーに合わせる。

## 5. バランスの検証（私が行う）
- BOTを**4キャラ分**にする（各キャラの全ツリー最大振りで、主→第2→奥義の順）。合格基準（初期案）: 各キャラとも本編が周回数490〜510・model_hours 20.8〜21.2・Lv124付近、敗北≤30、塔・深淵が今の基準の±帯。**キャラ間の差は±5%以内**を目標。
- 弱いキャラが出たら、倍率・MP・CT・パッシブを調整（数値調整は私が仕様化し、Geminiが適用）。
- SPの総量を確認: 1キャラ分は90SP（奥義込みで最大120SP程度）。総獲得SP（約300）で、1キャラ最大＋他キャラも少し育成できる量になる。
