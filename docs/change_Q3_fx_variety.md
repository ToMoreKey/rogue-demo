# 変更書: Q3（スキルエフェクトの個別化・格上げ）

## 1. 背景
運営者要望（2026-11-25、Q2のエフェクト確認パネルで確認）。
- 強撃と必殺剣、連続斬りと烈火斬・英雄の奇跡、強撃と天翔斬のエフェクトが同じに見える。
- 魔法・大技/奥義・回復も、**強いスキルほど豪華**にし、**スキル同士で見た目が被らない**ようにしたい。
Q1の演出は、分類（斬撃・魔法・大技・回復）ごとに共通の見た目＋色違いだったのが原因。

## 2. 方針
- 対象: 斬撃(6)・魔法(8)・大技/奥義(8)・回復(10)の合計32スキル。**強化（バフ）は今回は変えない**。
- 各スキルに、固有の演出（モチーフ・動き・形）を持たせる。同じ分類の中で、色違い・本数違いだけで済ませない。
- **格付け（ティア）**: 威力（倍率×ヒット数、MP、回復量）が上のスキルほど、①演出が長い ②要素の数・大きさが大きい ③画面を覆う範囲が広い ④閃光・ぶれが強い。下位は短く控えめ、最上位は派手。
- 上限は維持: 同時の演出要素は最大12個（必要なら16個まで引き上げてよいが、その場合は報告に書く）、演出の長さは最大1200ms（ゲーム速度が速いと比例して短縮、最短150ms）、`transform`/`opacity` 中心。実戦闘のタイミング・ダメージ計算・乱数・BOT結果は変えない（表示のみ）。`prefers-reduced-motion`、戦闘エフェクトOFF、Q2パネルの動作は従来どおり。
- 外部ライブラリ・画像は使わない（CSS・DOM・インラインSVG）。

## 4. 守ること
数値・バランス・BOT結果・セーブ形式(v8)・`to_dev`の分離・Q1/Q2の設定（ON/OFF、reduced-motion、確認パネル）を変えない。強化（バフ）の演出は変えない。仕様と矛盾する判断は勝手に決めず「要確認」と書く。

## 5. 合格基準
1. 対象32スキルが、それぞれ固有の演出識別子（signature）を持ち、重複がない（同じ分類の中で被らない。テストで全signatureの一意性を確認）。
2. ティアが上のスキルほど、演出時間・要素数・覆う範囲のいずれも下位以上で、最上位が最も豪華（テストで、各スキルの「演出の長さ」「要素数」を取得し、同分類内で順序が崩れていないことを確認）。
3. 全スキルで、演出が規定時間内に終わり、要素が溜まらない（上限内）。高速連打でも崩れない。ページエラーなし。
4. 演出の有無で戦闘結果が一致する（Q1のテストが引き続き通る）。BOT結果が不変。
5. Q2のエフェクト確認パネルで、全32スキルが再生できる（パネル側の変更は最小限で、分類表示の整合は保つ）。
6. 360/390/420pxで崩れない。reduced-motionで激しい演出が出ない。
7. 全テストOK、ビルド再現。
