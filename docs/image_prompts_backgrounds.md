# ダンジョン背景プロンプト（A〜O の15ダンジョン＋天蓋の塔＋深淵、計17枚）

Gemini（画像生成）に渡す。**参照画像として敵一覧シート（`sheet1.png` など、敵のドット絵）を添付**してから各プロンプトを貼ると、敵・キャラとの画風が揃う。
出来上がった画像を私（Claude）に渡すと、横長にトリミング・軽量化（WebP/PNG）して `src/assets/` に埋め込み、現在のSVG背景と差し替える（戦闘画面・ダンジョン選択のバナー・各画面の見出しで使用）。

## 共通ルール（各プロンプトに含めてある）
- **画風**：参照画像の敵と同じ高解像度ドット絵（ピクセルアート）。黒に近い紺の太めの輪郭、くっきりした陰影、色数は多めだが塗りは平坦。
- **サイズ・比率**：横長 16:9（できれば 2048×1152 以上）。ゲームでは中央を中心に切り出して使うため、**重要な要素は画面の中央〜中央下に**置く。上下の端に重要物を置かない。
- **構図**：奥行きのある横スクロール戦闘ゲームの背景。**手前（下 35%）は平らな地面（床）**にして、左側にプレイヤー、右側に敵が立つ。**中央〜右下には物を置かず**、広く空ける。
- **入れないもの**：人物・キャラクター・敵・文字・ロゴ・UI・枠。
- **明るさ**：戦闘の見やすさのため、地面と中景は**やや暗め・低コントラスト**。遠景に見せ場（光・シルエット）を置く。
- **雰囲気の色**はダンジョンごとに指定（ゲーム内のテーマカラーに合わせてある）。

## 共通の書き出し（各プロンプトの先頭に付いている）
「参照画像と同じ高解像度ドット絵のスタイルで、横長16:9のゲーム戦闘背景を1枚描いてください。人物・敵・文字・UIは描かない。手前の下35%は平らな地面で、中央〜右下は広く空ける。中景・地面はやや暗めで低コントラスト、遠景に見せ場を置く。」

## 出来上がったあとの流れ
1. 17枚の画像をこちらに渡す（まとめて、または数枚ずつでよい。どのダンジョンか分かる名前・順番で）。
2. 私が横長にトリミングし、軽量化して埋め込み、現行のSVG背景と差し替える（足りない分は今のSVGのまま）。
3. 戦闘画面での見え方（キャラ・敵が背景に埋もれないか）を確認し、必要なら暗めの重ねで調整する。
4. devで確認 → 「公開して」で本番へ。

## うまくいかないときの調整
- キャラの立つ場所に物が置かれる → 「中央〜右下に物を置かない」を強調して再生成。
- 絵が明るすぎて敵が見づらい → 「全体をもう少し暗く、低コントラストに」と指示。
- 画風が敵とずれる → 参照画像を再添付し、「参照画像と同じ線の太さと塗りで」と指示。
