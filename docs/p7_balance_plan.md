# P7 数値バランス調整 計画

デバッグ部隊の通しプレイ（`release_checklist.md` #15）の結果を受けて、**数値だけ**を調整するフェーズ。新機能・UI変更・画像差し替えは行わない。

## 1. 進め方
1. デバッグ部隊が通しプレイし、下の「2. 報告テンプレート」で回答する。
2. Claude が回答を集計し、調整案を `docs/p7_tuning_list.md` にまとめる（項目・現状・案・影響範囲）。
3. 運営者が採用する項目を決める。
4. 採用項目だけを Gemini に依頼する（`docs/gemini_prompt_P7.md` の「調整項目」欄を埋めて貼り付ける）。
5. Claude が BOT 回帰・テスト・ビルド再現を検証する。
6. 公開前チェックリストへ。

## 2. デバッグ部隊 報告テンプレート
- 進行: どこまで進めたか／総プレイ時間／使ったプレイ速度
- 詰まった箇所: ダンジョン名・階層・敗北回数・何で突破したか
- 退屈・作業感のあった箇所（周回が長い／戦闘が長い／SPやゴールドが余る・足りない）
- 強すぎ・弱すぎる装備、スキル、特性、祝福、極意
- ボス（特に終焉神ニヒル、深淵の主）の体感難度（簡単／ちょうど良い／厳しい）
- 回廊: 到達階、祝福の選び方、回廊コインの貯まり方
- 深淵: 挑戦した難度と結果
- 不具合（再現手順つき）。数値ではなく不具合のものは P7 に含めず別修正にする。

## 3. 調整してよいもの・いけないもの
調整してよい: 敵のHP/ATK/DEF/EXP/ゴールド、ドロップ率、装備の性能値、スキル倍率・コスト、祝福の効果量、極意の効果量とコスト、回廊コインの獲得量と交換価格、深淵の呪いの強さ、実績・図鑑の報酬量。

変えてはいけない: セーブ形式、画面・UI、画像、ダンジョンの数と構成、解放条件、LV_CAP、ID（セーブ互換のため）。

## 4. 合格基準（調整後も守る）
- 本編周回BOT: 3シード `done: true`、ラン数490〜493 を**目標範囲として維持**（QA の結果、範囲自体を変える場合は運営者が先に決める）、20.85〜20.94時間、Lv124。
- 回廊BOT: 最適59/64/69、ランダム51/53/59 付近（調整対象に回廊を含む場合のみ動かしてよい。動かす場合は目標値を先に決める）。
- 深淵BOT: 標準 d1〜3 は100%、強化 d10 は 0〜20%。
- 全テスト `RESULT: OK`、ビルド再現、420px 崩れなし。
- 調整した項目は、変更前→変更後の値を `docs/dev_notes_P7.md` に表で残す。
