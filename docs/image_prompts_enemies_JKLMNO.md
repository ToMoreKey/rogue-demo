## 共通の前置き（各プロンプトの先頭に入っている）
```
重要: 必ず「ドット絵（ピクセルアート）」で描くこと。ピクセルの粒がはっきり見える16ビット風で、限られた色数、アンチエイリアスなし、細かいグラデーションなし。滑らかなイラスト・ベクター風・水彩風は不可。添付した参照画像（既存の敵シート）のドットの粗さと同じにする。キャラクターの名前などの文字は一切入れない（ラベル・キャプション・見出しは禁止）。セルの区切り線・枠線も入れない。
```

## Jシート: 幻霧の大湿原

```
添付した参照画像（既存の敵シート）と全く同じ画風で、新しいモンスター6体のシートを描いてください。
頭身の低いデザイン、太めの濃い輪郭、くっきりした陰影。ゲームの敵キャラクターとして使います。

1. 泥人形ボグ（スライム型）: 沼の泥と水草でできた、ぬるぬるした泥の塊の生き物。茶緑色、目は小さく虚ろ、体から泡がぽこぽこ出る。
2. 彷徨う鬼火: 青白い炎の塊に、笑う顔がある。尾を引いて宙に浮く。中心は白く、縁は青緑色。

4. 沼鰐の戦士（リザードマン）: 鰐の頭を持つ二足歩行の戦士。緑の鱗、錆びた銛と木の盾、牙をむく。

6. 沼の主ヒュドラ（ボス・他より一回り大きく、セルほぼ全体）: 三つ首の大蛇（ヒュドラ）。濃い緑の鱗、紫がかった腹、3つの首がそれぞれ牙をむき、毒液を垂らす。威圧感。
```
