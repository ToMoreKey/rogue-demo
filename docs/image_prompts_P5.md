# P5用 画像プロンプト（装備アイコン★6〜9＝8枚、深淵の主＝3枚）

使い方はこれまでと同じ。Gemini（画像生成）に、参照画像を添付してから、コードブロックの中身をそのまま貼る。出来上がった画像は私（Claude）に渡す。私が背景を抜いて切り出し、`src/assets/` に埋め込む。
各プロンプトの先頭「【厳守】」は、これまでの失敗（ベクター風・文字入り・枠線入り）を防ぐためのもの。消さずにそのまま貼ること。

| 素材 | 枚数 | 参照画像 | ID |
|---|---|---|---|
| 装備アイコン（武器★6〜9、防具★6〜9） | 8（1シート・4列×2行） | 既存の装備アイコンシート（★1〜5） | weapon6〜9 / armor6〜9 |
| 深淵の主 | 3（1シート・3列×1行） | 既存の敵シート（D〜Iの採用版など） | abyss_gula / abyss_mirror / abyss_deep |

## 装備アイコン★6〜9（8枚）
参照画像: 既存の装備アイコンシート（上段が剣★1〜5、下段が防具★1〜5）を添付する。

| ★ | 武器 | 防具 |
|---|---|---|
| 6 | 竜殺しの大剣 | 古竜の鎧 |
| 7 | 時渡りの剣 | 雷霆の鎧 |
| 8 | 魔王殺しの神剣 | 機神の鎧 |
| 9 | 創世の剣 | 創世の鎧 |

```
【厳守】
- 必ず「ドット絵（ピクセルアート）」で描くこと。ピクセルの粒がはっきり見える16ビット風で、限られた色数、アンチエイリアスなし、細かいグラデーションなし。滑らかなイラスト・ベクター風・水彩風・3DCG風は不可。
- 添付した参照画像（既存の装備アイコンシート）と同じ画風・同じドットの粗さ・同じ太さの輪郭・同じ構図（剣は右上に刃先を向けた斜め置き、防具は正面から見た上半身用の鎧）にすること。
- 文字（名前・数字・★・ラベル・キャプション・見出し）は一切入れない。セルの区切り線・枠線・影・床・台座・光の輪も入れない。
- 背景は単色のマゼンタ（#FF00FF）で塗りつぶす。装備の色にマゼンタ系（ピンク〜赤紫）は使わない（紫は青寄りの青紫にする）。
- 各アイコンは1つのセルに1つ、セルの中央に高さの約80%で収める。はみ出さない。
- 上の段が武器、下の段が防具。左から右へ★6、★7、★8、★9の順（右へ行くほど強く、豪華に、大きく見えるようにする）。

添付した参照画像（既存の装備アイコンシート）と全く同じ画風で、新しい装備アイコン8個のシートを描いてください。4列×2行（同じ大きさのセル8つ）。

上段（武器・剣）:
1. ★6 竜殺しの大剣: 幅広の大きな両手剣。刃は暗い鋼色で、竜の牙のような鋸状の刃、鍔は竜の爪の形。柄は黒革、柄頭に赤い宝石。
2. ★7 時渡りの剣: 細身の剣。刃は淡い紫がかった銀色で、刃の中に砂時計と歯車の細い模様。鍔は金色の円環（時計の輪）、柄頭に水色の宝石。
3. ★8 魔王殺しの神剣: 大振りの聖剣。刃は白金に光り、刃の中心に青白い光の筋。鍔は翼の形で金色、柄は白と金。刃の根元に紫の宝石。
4. ★9 創世の剣: 最も豪華な大剣。刃は虹色にきらめく白い光の結晶でできている。鍔は黄金の大きな翼と星、柄は白金、柄頭に大きな光の宝珠。全体から淡い光の粒（ドット数個）が舞う。

下段（防具・上半身の鎧）:
5. ★6 古竜の鎧: 暗い緑と黒の竜鱗の鎧。肩当ては竜の角のように尖る。胸に金の縁取りと竜の顔の紋章。
6. ★7 雷霆の鎧: 濃い青紫の鎧。金と黄色の稲妻の模様が走る。肩当ては雷雲のように大きい。胸に黄色い稲妻の紋章。
7. ★8 機神の鎧: 白と銀の機械的な鎧。歯車と青い光の回路の線、胸の中央に大きな青いコア（水色の光る球）。肩当ては重厚で角ばっている。
8. ★9 創世の鎧: 最も豪華な鎧。白金と虹色の光の結晶でできている。胸に光の宝珠と星の紋章、肩当ては大きな翼のよう。全体から淡い光の粒（ドット数個）が舞う。
```

## 深淵の主（3体）
参照画像: 既存の敵シート（D〜I、J〜Oの採用版のうち1〜2枚）を添付する。
3体は、無限の深淵の底にいる主。これまでのボスと違い、「黒・暗い青緑・白い光」の統一感（深淵の色）を持たせる。

```
【厳守】
- 必ず「ドット絵（ピクセルアート）」で描くこと。ピクセルの粒がはっきり見える16ビット風で、限られた色数、アンチエイリアスなし、細かいグラデーションなし。滑らかなイラスト・ベクター風・水彩風・3DCG風は不可。添付した参照画像（既存の敵シート）のドットの粗さと同じにする。
- キャラクターの名前などの文字は一切入れない（ラベル・キャプション・見出し・数字は禁止）。セルの区切り線・枠線・影・床・吹き出しも入れない。
- 背景は単色のマゼンタ（#FF00FF）で塗りつぶす。体・装備・エフェクトにマゼンタ系の色（ピンク〜赤紫）を使わない（紫は青寄りの青紫にする）。
- 1つのセルに1体、全身、正面〜やや斜め、セルの中央に収める。体が隣のセルにはみ出さない。3体とも「ボス」なので、セルほぼ全体（高さの約90%）を使い、堂々と大きく描く。

添付した参照画像（既存の敵シート）と全く同じ画風で、新しいボス3体のシートを描いてください。3列×1行（同じ大きさのセル3つ）。頭身の低いデザイン、太めの濃い輪郭、くっきりした陰影。ゲームの最強クラスの隠しボスとして使います。
共通テーマ: 深淵（海の底より暗い虚空の底。黒、暗い青緑、白く光る目や亀裂、ところどころに泡と光の粒）。

左から右へ、次の順番で配置:
1. 喰らう深淵グラトス: 巨大な口だけでできたような、黒い肉塊の怪物。大きく裂けた口に白い牙が何重にも並び、口の奥は青白く光る。体のあちこちから、先端に小さな目のある黒い触手が伸びる。暗い青緑の斑点。
2. 映す深淵ミラージュ: ひび割れた巨大な鏡の甲冑をまとった騎士のボス。鎧の表面は黒い鏡のようで、ひびの中に白い光が漏れる。顔のない兜、鏡の破片でできた大剣と、宙に浮く鏡の破片が数枚。
3. 沈める深淵アビサル: 巨大な深海の神のような存在。上半身は黒い人型で、下半身は長い黒い触手の束になって地の底へ沈んでいる。顔は白く光る大きな一つ目だけ、頭上に暗い青緑の光輪、体のあちこちに白い光の亀裂と小さな泡。
```
