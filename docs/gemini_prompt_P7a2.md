## 【プロンプト本文（ここから貼り付け）】

あなたは、ブラウザで動くローグライクRPG「rogue-demo」の開発担当エンジニアです。リポジトリ `ToMoreKey/rogue-demo` の `dev` ブランチ（最新を取得してから）で作業します。方針は `docs/change_P7a.md`（運営者の決定は6章）に書いてあります。

### 0. 前提（これまでと同じ）
- `src/` を編集し、`python3 tools/build.py` で `index.html` を生成する。`index.html` は直接編集しない。`sw.js` の `CACHE` を上げる。`src/assets/` は触らない。
- `window.__rogue` と `window.G` を残す。外部ライブラリを追加しない。
- 作業は `dev` ブランチ。`main` には push しない。push はこれまでと同じ方法（トークンは設定ファイルから読み、その場の変数で使い、画面・ログ・ファイル・コミット・報告に出さず、使い終わったら破棄する）。既存コミットの書き換え・force push はしない。
- セーブ形式・ID・画像は変えない。既存セーブが壊れないこと。420px幅で横スクロールが出ないこと。

### 1. ゴール（P7a-2: スキルツリーのパッシブ効果を説明どおりに反映し、敵を一括再調整して基準を戻す）
P7a-1 の完了後に行う。

### 2. やること
#### 2-1. 反映する（`docs/change_P7a.md` 3-1・6章）
- `sword15`（攻撃+15%）、`warrior10`（攻撃+30%）、`hero10`（攻撃+25%）: `playerAtk`（`src/js/20_state.js`）に `passiveBonus(p).atkMult` を掛ける。`p.passiveSkills` が空のときは掛けない（`p.mastery` と同じ扱いで、空オブジェクトでも結果が変わらないこと）。
- `mage10`（MP消費-20%）: スキル使用時の `p.mp -= s.mp`（`useSkillEffect` と攻撃スキル側）、スキルが使えるかの判定、画面表示のMP消費のすべてに `passiveBonus(p).mpCostMult` を反映する（消費は `Math.max(1, Math.round(s.mp * mpCostMult))`。`s.mp` を参照している箇所を `grep` で全部洗い出す）。
- `cleric10`（回復+50%）: `useSkillEffect` の回復に `passiveBonus(p).healMult` を掛ける（ポーションは対象外）。
- `hero10` の説明文（`src/data/skills.js`）を「パッシブ：攻撃・最大HP・最大MPが25%上昇」に直す。防御力には効かせない。
- ステータス画面などの表示値が、実際の計算と一致すること（今回反映する攻撃力・MP消費・回復量）。
#### 2-2. 再調整（敵の一括倍率のみ）
- 調整してよいのは `TUNE`（`src/data/config.js`）の敵側の一括倍率（`atkScale`、`hpScale`、`bossHp`、`bossAtk` など）だけ。個別の敵・ドロップ・装備・スキル倍率・回廊の祝福・深淵の呪いは動かさない。
- 目標（基準値）:
  - 本編周回BOT: 3シード `done: true`、ラン数490〜493、`model_hours` 20.85〜20.94、1階あたりティック4.06〜4.13、Lv124。
  - 回廊BOT: 最適59/64/69、ランダム51/53/59（±2階以内）。
  - 深淵BOT: 標準 d1〜3 は100%、d6〜10 は0%、強化 d10 は0〜20%。
- 調整は小さい刻みで行い、そのたびに BOT で確認する。`TUNE` だけで回廊・深淵が基準に戻らない場合は、勝手に別の数値を動かさず、現状の結果を報告に載せて「要確認」とする。
- BOT がパッシブを実際に取得しているか（`tools/bot.py` のSP割り振り）を確認し、結果を報告に書く。BOT の調整はしない。

### 3. 守ること（厳守）
- 上記以外の数値・仕様を変えない。セーブ形式を変えない。
- 変更前→変更後（反映した式・`TUNE` の値）を表にして `docs/dev_notes_P7a2.md`（新規）に残す。
- `tools/test_p7a2.py`（新規）を追加し、`README.md` に実行方法を書く（各パッシブの効果が出る／外すと元に戻る、MP消費の下限1、`passiveSkills` が空のとき結果が変わらない、表示値が計算と一致、旧セーブの読み込み）。
- 全テスト（`test_p1` 〜 最新、`test_save_migration`）が `RESULT: OK`。ビルドが再現できる（`cmp`）。
- 秘密情報を入れない。仕様と矛盾する判断は勝手に決めず「要確認」と書く。
