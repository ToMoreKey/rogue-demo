# 変更書: P7b（本編序盤の難易度を下げる）

## 1. 背景
P7a-2 で `TUNE`（`hpScale` 1.35、`atkScale` 1.02、`bossHp` 2.5、`bossAtk` 1.4）を一括で上げた結果、序盤が厳しくなった。スキル未習得の新規プレイヤーで比較（ダンジョンA初級を10回挑戦）:
- P7a の前: 3回目で初クリア、その後は安定。
- 現在: 10回挑戦してもクリアできない（Lv4止まり）。

終盤（パッシブ取得後）に合わせた一括倍率が、序盤にも掛かっているのが原因。**本編の序盤だけ、敵のHPと攻撃力を弱める**（運営者承認 2026-11-20）。

## 2. 方針
- 対象: 本編（通常ダンジョン）の序盤だけ。回廊・深淵・後編（J〜O）は変えない。
- 方法: 敵の生成（`src/js/40_game.js` の `spawnEnemy` 付近）に、「序盤緩和」の倍率を足す。倍率の表は設定ファイル（`src/data/config.js`）に置く。`TUNE` の既存値は変えない。
- 倍率の形（初期案。Gemini が調整する）: ダンジョン × 難易度 ごとに `{ hp, atk }`。
  - A 初級 0.70 / 0.80、A 中級 0.80 / 0.88、A 上級 0.90 / 0.95
  - B 初級 0.80 / 0.88、B 中級 0.88 / 0.93、B 上級 0.95 / 0.98
  - C 初級 0.90 / 0.95、C 中級 0.95 / 0.98
  - それ以外は 1.0（変えない）
  - ボスにも同じ倍率を掛ける（ボスだけ重いと、序盤で詰まるため）。
- 倍率は敵のHPと攻撃力のみ。防御・経験値・ゴールド・ドロップは変えない。

## 3. 合格基準
1. **序盤の手触り**（新規プレイヤー、同じ条件で測る）:
   - スキル未習得でも、A初級を平均4回以内にクリアできる（P7a 前は3回目）。
   - 初期3SPで回復スキルを習得した場合は、A初級の最初の5回のうち4回以上クリアできる。
   - A → B → C の初級を、極端な詰まり（同じダンジョンで連続5敗）なしで順に進められる（自動プレイ＋通常の装備更新）。
2. **終盤・他モードは不変**:
   - 本編周回BOT: 3シード `done: true`、ラン数490〜510、`model_hours` 20.8〜21.2、Lv124、敗北30回以下（新基準。`docs/p7_balance_plan.md` 4b章）。できれば P7a 完了時点（508/492/497ラン、21.15/20.89/20.94h）から大きく動かさない。
   - 回廊BOT・深淵BOT は**完全に同じ結果**（序盤緩和は本編だけに効くため）。
3. 全テスト OK、ビルド再現、セーブ形式は変えない。
