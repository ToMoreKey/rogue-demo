## 3. EXP カーブ（`expNeed`）
```js
const expNeed = lv => Math.round(17.5 * Math.pow(lv, 1.55) * (lv >= 30 ? 1 + (lv - 29) * 0.015 : 1));
```
- 1セルあたり平均5〜6ランの周回で推奨Lvへ届き、極級制覇時に Lv55〜56 付近へ到達する設計。

## 4. 戦力値（`gearPower`）と自動装備スコア（`gearScore`）
```js
const itemPower = it => Math.max(1, Math.round((it.slot === 'weapon' ? WEAPON_BASE : ARMOR_BASE)[it.star] * RARITY[it.rarity].mult * it.roll));
const weaponAtk = it => it ? Math.round(itemPower(it) * ((it.prop && PROPS[it.prop].atkMult) || 1)) : 0;
const gearPower = it => !it ? 0 : (it.slot === 'weapon' ? weaponAtk(it) : itemPower(it));
const gearScore = it => {
  if (!it) return 0;
  const pw = itemPower(it);
  if (it.slot === 'armor') return pw;
  return pw * (it.prop === 'flame' ? 1.2 : it.prop === 'vamp' ? 1.05 : 1);
};
```
- 表示用の戦力値（`gearPower`）は特性倍率を含む実効攻撃力／実効防御力を表示する。
- 自動装備（`equipBest()` / `receiveItem()`）と「おすすめ」マーク（`bestGearItem()`）は `gearScore` を使い、HP消費リスクのある「狂気（`madness`）」武器は倍率1.0かつ自動装備の対象外（手動装備専用）とする。

## 5. ゴールド消費・収入バランス（P1c）
- **`TUNE.goldScale`**: `0.30`
- **`sellValue`**: `Math.max(1, Math.round(RARITY[it.rarity].sell * 0.65 * (1 + (it.star - 1) * 0.5) * (0.6 + 0.4 * it.roll)))`
- **鍛冶強化（`smithCost`）**: `Math.floor(Math.pow(it.star, 3) * 28 * RARITY[it.rarity].mult)`（★2→3 コモン `224G`、★5→6 レジェンド `12,250G`）
- **再鍛造（`reforgeCost`）**: `Math.max(80, Math.floor(smithCost(it) * 0.9))`
- **ショップ（`SHOP_ITEMS`）**: 生命の薬 200G / 魔力の薬 250G / 初級石 800G / 中級石 2,800G / 上級石 9,000G
- **バッグ拡張（`BAG_EXPAND_COSTS`）**: 60→70: 4,000G / 70→80: 8,000G / 80→90: 16,000G / 90→100: 26,000G / 100→110: 40,000G / 110→120: 56,000G（最大120枠、合計150,000G）
- **スキルリセット（`skillResetCost`）**: `Math.max(50, p.lv * 50)`
